# Windows x64 + x86 安装与 EmEditor 32 位修复

Copyright © 2026 立方田 <managecode@gmail.com>

本包用于 **64 位 Windows 上同时运行 32 位与 64 位应用**，不是 32 位 Windows 系统安装包。修复原包只有 x64 TSF DLL、无法加载到 EmEditor 32 位进程的问题；仍需在 EmEditor 7.00.3 上进行实际输入验收，不能仅凭交叉编译证明所有旧编辑控件兼容。

## 升级

1. 关闭 EmEditor 和其他正在使用 Zhimo 的编辑器。
2. 解压整个 ZIP，不要只复制 DLL。
3. 使用平时输入文字的同一个 Windows 账户打开管理员 **64 位 PowerShell**，进入解压目录。
4. 已安装 Zhimo 时执行下面的命令；首次安装不加 `-Upgrade` 参数。

从 GitHub 下载的 ZIP 可能带有互联网阻止标记。新版入口先提示校验来源和 SHA-256，
仅在你明确输入 `UNBLOCK` 后解除当前包目录中 `.ps1` 文件的阻止标记，不修改系统执行策略。
组织强制要求签名时会停止，请联系管理员，不绕过组织策略。

```powershell
.\install.cmd -Upgrade
```

安装器检查所有文件校验值，分别运行 x64/x86 核心与 COM 导出探针，然后复制到新的 `C:\Program Files\Zhimo\Builds\<build-id>` 目录。根目录放 x64 DLL，`x86` 子目录放 x86 DLL。使用 `System32\regsvr32.exe` 注册 x64，使用 `SysWOW64\regsvr32.exe` 注册 x86，并检查对应注册表视图。失败会尝试恢复原来两个视图的注册；恢复失败会明确警告。不会删除旧安装包或用户词库。

5. **注销 Windows 并重新登录**，再启动 EmEditor。
6. 切换到 Zhimo 中文模式，输入 `nihao`、`nh`、`wm`、`zhimo` 并选择汉字上屏。再在一个 64 位应用中测试相同输入。

## 浮动状态栏

默认显示白底蓝色紧凑状态栏：`Z | 中/英 | 手 | 麦 | ⋯`。

- 点击「中/英」切换输入模式，与 Shift+Space 使用同一切换逻辑。
- 点击「手」「麦」打开手写或离线语音面板。
- 点击「⋯」或右键状态栏，选择「水平显示」「垂直显示」或「隐藏浮动状态栏」。
- 按住 Z 区域拖动，可在各显示器可见工作区内任意移动，不限于屏幕边缘。
- 隐藏后，右键系统任务栏的 Zhimo 输入模式图标，选择「显示浮动状态栏」恢复。
- 显示设置、横竖布局、拖动位置保存在当前用户注册表；32/64 位应用共享设置，下次激活时读取。布局变化或显示器移除后自动限制到可见工作区。
- 浮动窗口不抢编辑焦点，切换离开应用时隐藏；系统原有模式标识保留。
- 重复状态栏修复：以当前前台线程为准显示，线程失焦时隐藏，并通过会话内命名互斥锁保证新版实例最多显示一条。150 毫秒检查兜底处理通知遗漏；宿主退出后可恢复锁所有权。宿主卡死时新栏可能暂时不显示，但不会为争抢状态栏阻塞输入线程。
- **从重复状态栏旧版升级后必须注销并重新登录**：旧进程中已加载的 DLL 不会因安装新包自动替换。新包不强制终止编辑器，避免丢失未保存文档。

本次已交叉编译两种架构，新增横竖布局的 DPI 命中测试随 Windows 探针运行；实际 Windows 多屏拖动、状态栏显示及 EmEditor 输入仍需实机验收。

## 验证和诊断

- `check-installed.cmd` 应显示 CurrentUser / Registry64 与 Registry32 都指向本次 build，32 位路径以 `x86\ZhimoTsf.dll` 结尾。
- `diagnose-emeditor.cmd` 最多等待 60 秒；用鼠标点击 EmEditor 正文并保持焦点，脚本会显示真实 EmEditor 位数与窗口类，不读取文档内容。
- Windows x64 进程不能加载 x86 DLL，反之亦然。不要把两种架构的同名 DLL 混放或相互覆盖。
- 32 位 TSF 通过私有管道启动根目录中的独立 64 位手写/语音程序；不在 EmEditor 32 位进程内加载语音模型。
- 包未代码签名。SHA-256 只能核对文件完整性，不能认证发布者。

卸载时从本次安装目录运行 `uninstall.cmd`。它预先检查两个注册视图都属于本包，再注销两种架构；文件和个人词库保留。不要从旧版本目录运行卸载脚本。

微软说明：[64 位平台上的 TSF 双架构部署](https://learn.microsoft.com/en-us/windows/win32/tsf/64-bit-platform-considerations)。本包不是独立的传统 IMM32 `.ime` 实现；如果 32 位模块已加载而旧控件仍无法输入，需要另查焦点、输入范围及编辑会话。
