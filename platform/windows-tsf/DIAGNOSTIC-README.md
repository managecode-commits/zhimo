# 样式没有变化：无需重装的诊断

这个包不是新输入法安装包，不会注册/卸载 DLL、修改输入法设置、停止进程或覆盖文件。
它用于区分“仍安装/注册旧 DLL”“EmEditor 未加载 Zhimo”“新版候选路径仍失败”。

1. 先在 EmEditor 中选择 Zhimo，输入一次 `nihao`，保持 EmEditor 打开。
2. 完整解压本包，运行 `check-installed.cmd`，把控制台输出截图或复制给开发者。
   它显示 COM 注册路径、已知包的磁盘 DLL 哈希及 EmEditor 已加载模块路径。
3. 再运行 `diagnose-emeditor.cmd`，8 秒内切回 EmEditor 并点击文档编辑区，提供输出。
4. 同时提供当前输入截图、Win+空格输入法列表、EmEditor 的版本与 x64/x86 信息。

无需管理员权限才能启动；若 EmEditor 权限较高或系统策略限制模块枚举，诊断可能显示无法读取。
这不表示 DLL 没有加载。请保留错误输出，不要关闭安全软件或绕过组织策略。
CMD 仅为诊断 PowerShell 进程选择 RemoteSigned，不修改持久执行策略。

读取范围仅为 Zhimo 注册项、对应 DLL 文件和 EmEditor 进程/窗口类；不读取编辑内容、窗口标题或录音。
输出会包含安装路径、进程名称和运行账户；发送时可以遮住账户名和个人目录部分。

注意：读取已加载模块的路径，并对该路径的磁盘文件算哈希，**不等于验证进程内存中的 DLL 字节**。
即使磁盘文件是新版，仍需结合注册位置、进程启动时间和实际界面判断。
诊断脚本尚未在真实 Windows PowerShell 上执行；执行报错时请提供原始输出。
