# Zhimo Windows x64 测试包

桌面手写／语音版（完整包才包含 `zhimo-desktop-panel.exe`、语音 DLL 和模型）：

- Ctrl+Shift+H 打开单字手写；Ctrl+Shift+F10 打开离线语音。Ctrl+Shift+V 仍留给应用粘贴纯文本。
- 也可右击任务栏中／英按钮，选择“手写输入”或“离线语音”。
- 手写支持撤笔、清空、最多 100 个候选，点击候选上屏。
- 语音点击开始才录音，最长 60 秒；停止后离线识别，点击确认才上屏；取消不提交。
- 使用系统默认麦克风，当前 WinMM 采集要求支持 16 kHz 单声道 PCM；暂未提供设备选择／重采样回退。
- 输入法失焦、键入新内容会取消面板；提交时重新检查原上下文、选区及密码范围。
- 首次选择功能可能需要模型加载；原生界面尚未经过 Windows 实机、触控笔、高 DPI 验收。

原生任务栏状态版：移除旧的右下角悬浮按钮，改为 Windows 输入指示器中的“中／英”模式图标，
位于 Zhimo 品牌图标旁；通过 GUID_LBI_INPUTMODE 发布，并在 MinGW/MSVC 注册系统托盘支持。
点击“中／英”与 Shift+Space 共用切换逻辑；品牌图标是输入法选择入口，不是模式按钮。
切换时取消未确认组合。鼠标切换通过 TSF 编辑会话执行，焦点已改变的延迟请求会取消；
密码或不允许输入的上下文不切换。图标颜色交由 Windows 主题处理，不绘制常驻浮窗。
安装前 probe 包含模式文字、图标、COM 通知和点击回调检查，不等同于系统托盘集成测试。
请实机验收：选择 Zhimo 后，任务栏出现“中”；Shift+Space 改为“英”；点击后恢复“中”，
继续输入 nihao 可选“你好”。再测试浅色／深色任务栏、125%／150% 缩放和切换应用。
当前只通过交叉编译与打包检查，尚未在 Windows 实机执行新增 probe 或验证系统托盘。

实体键盘版：Shift+Space 切换中英文。英文模式直接输入原始字母、大小写、数字和标点，
不自动替换为联想词；中文模式支持拼音候选、数字选词和空格上屏。Shift+数字不再误选词，
Shift+引号不再强制输入拼音分隔符；有组合时标点先结束选词再交给宿主输入。
以上 Windows 键事件行为仍需实际应用验收，不代表已经验证 EmEditor。

EmEditor / 横排候选版：对当前 EmEditor 进程中有焦点、与 TSF 上下文关联的
`EmEditorView` 文档窗口增加无学习的输入范围回退；显式密码/PIN 仍透传。
候选栏调整为上方拼音、下方横排候选，首项红色，其余蓝色，支持点击选词和箭头翻页。
此改动已交叉编译，尚未在真实 EmEditor 中验证，也未证明所有 EmEditor 版本均使用该窗口结构。
若仍不能输入，运行 `diagnose-emeditor.cmd`，8 秒内切回 EmEditor 编辑区，再提供控制台输出。
诊断只读取进程名称与窗口类，不读取文档内容、标题或键入文本。

拼音初始化修复版：首次启用即选择底层拼音引擎，不再出现 Windows 标记为中文、
底层却处于英文模式的初始化不一致。旧测试包用户请先切回微软拼音并关闭编辑器，
然后在同一账户的管理员 PowerShell 中运行新包的 `./install.ps1 -Upgrade`。
升级使用不同目录，不覆盖旧 DLL；失败时尝试恢复旧注册并输出恢复结果。完成后注销登录。
不要删除 `%LOCALAPPDATA%\Zhimo\user`，以保留学习词库。

这是未进行 Authenticode 签名的开发测试包，不是正式发行版。当前只交叉编译和检查了
PE 架构、导出、依赖闭包，尚未在真实 Windows 中验证注册、输入、卸载。
建议先在可还原的 Windows 10/11 x64 测试机或虚拟机使用，保留微软拼音。
本包没有 x86 DLL，不支持 32 位宿主；ARM64 Windows 不在本次验收范围。

## 安装

1. 将 ZIP **全部解压**到本地普通目录，不要直接在压缩包里执行脚本。
2. 在将使用输入法的 Windows 管理员账户中，右键 `install.cmd` → **以管理员身份运行**。
   不要用另一个管理员账户代装，因为当前 COM 注册与输入配置包含当前用户项。
3. 脚本先检查文件哈希并运行 `zhimo-tsf-probe.exe`，然后复制到
   `C:\Program Files\Zhimo\Builds\<包哈希前16位>` 并注册 TSF DLL；遇到已有安装默认拒绝，须显式 `-Upgrade`。
4. 注销并重新登录。按 **Win + 空格**选择“知墨输入法 · Zhimo”。
   若未出现，在 Windows“语言和区域”中打开“中文（简体，中国）”的语言选项，添加 Zhimo 键盘。
5. 先在传统 Win32 编辑器输入 `nihao`，检查候选“你好”、空格确认与退格。
   测试 Shift+空格切换中英、数字 1～9 选词、PageUp/PageDown 翻页。

CMD 启动器仅为本次 PowerShell 进程选择 RemoteSigned，不修改机器或用户的持久执行策略，
也不会覆盖组织组策略。下载文件的来源标记仍可能使未签名脚本被阻止。
如果 PowerShell 提示执行策略禁止脚本：不要全局关闭策略，也不要忽略组织管理规则。
检查包来源与下述说明后，可在允许的测试环境使用管理员 CMD 手动运行：

```bat
cd /d "解压后的完整目录"
zhimo-tsf-probe.exe
```

探针成功后，把该目录完整复制到一个永久目录，再在同一管理员 CMD 中设置该目录为当前目录和 DLL 搜索路径，执行：

```bat
set "PATH=%CD%;%PATH%"
%SystemRoot%\System32\regsvr32.exe "%CD%\ZhimoTsf.dll"
```

手动安装的用户必须记住该永久目录；卸载也需对**同一个 DLL 路径**使用 `regsvr32 /u`，
不要使用只处理默认安装目录的 `uninstall.cmd`。注册期间不要移动 DLL 文件。
包内 SHA256SUMS 只能帮助发现文件损坏，并不代替可信来源或代码签名。

## 当前能力与限制

- 中英文基础键盘输入、候选与本地学习；本包使用参考拼音引擎，不是 Android 的完整 Rime 词库。
- 完整桌面包已有基础单字手写与短句语音界面；未接入字形融合、连写、纠错学习、实时增量语音及独立设置窗口。
- 密码/PIN 透传、私密字段禁学习；未给出可靠输入范围的自定义控件可能完全透传。
- 候选点击、翻页、DPI 缩放及工作区避让已有实现；UI-less、无障碍、WinUI/AppContainer、Office/浏览器输入兼容性尚未验收。
- 请勿先在重要文档中测试；不要关闭 Defender、SmartScreen 或安装未知证书来绕过警告。

## 卸载

先切回微软拼音，关闭使用 Zhimo 的应用，然后在同一账户中以管理员身份运行**已安装目录内**的 `uninstall.cmd`。
脚本发送注销请求并保留文件。注销/重启后确认键盘列表不再有 Zhimo，再手动删除
脚本输出的精确版本目录。词库保留在 `%LOCALAPPDATA%\Zhimo\user`，不自动删除。
当前原生注销入口未完整传播所有 TSF 错误，因此脚本成功也仍需检查键盘列表。

## 出错时收集

请提供 Windows 版本、CPU 架构、安装脚本全部输出、使用的应用名称，以及故障截图。
运行 `check-installed.cmd` 可比较注册路径、包清单哈希、构建元数据和 EmEditor 已加载模块路径。
哈希匹配只表示磁盘文件一致，不代表已运行的编辑器卸载了旧 DLL，也不代替发布者签名。
`regsvr32` 报错可在管理员 CMD 切到安装目录，临时将其加入当前进程 PATH，再不带 `/s` 重试，
记录弹窗 HRESULT。切回微软拼音即可继续正常输入。
