# Android 键盘视觉与字号改版

日期：2026-09-13。本轮针对 Android 虚拟键盘，不宣称其他平台已复用这套视觉组件。

## 设计与实现

| 区域 | 标准字号 | 处理方式 |
|---|---:|---|
| 26 键字母 | 23sp | 主字符与长按角标分开绘制 |
| 数字键 | 26sp | 不再与符号页共用 16sp 小字号 |
| 九键字母组 | 22sp | ABC 等为主标签，数字为 12sp 角标，原按键语义不变 |
| 常用符号/底栏标点 | 22sp | 保留字符本身，不用截图或位图替代 |
| 功能文字 | 至少 15sp 的目标字号 | 紧窄按键可自适应到 14sp，避免整词裁切 |
| 候选汉字 | 22sp | 候选栏与展开面板使用同一套字号 |
| 拼音注释 | 14sp | 独立第二行；高对比度按实际背景选择黑/白文字 |

`KeyboardTypography` 集中管理字号，`KeyboardKeyView` 负责辅助角标和矢量图标，Service 继续处理输入行为。
设置中的“按键文字大小”提供标准、大字（1.15 倍）、特大（1.3 倍），与“键盘高度”独立。
按键在有限宽度中自适应：单字符下限 18sp，功能文字下限 14sp；不能保证在任意系统字体倍率下都维持目标最大字号。

- 删除、麦克风/停止、单手位置、Shift、展开/翻页、打开表情页统一为代码绘制的线条图标，不依赖 emoji 字体。保留原有无障碍名称；实际输入的 emoji 仍使用原字符。
- 单字符符号按字形实际轮廓居中，修复全角感叹号、冒号等预留字宽造成的视觉偏移；提交内容不变。
- 使用明确的圆角按键背景，去掉系统 Button 背景自带的额外视觉内缩；实际按键仍保留横向 2dp、纵向 3dp 外边距。
- 模式信息与候选内容分行，候选不再与模式名称争夺横向空间。
- 展开候选按可用宽度和字号选择 2–5 列，参考引擎分页容量随列数调整；Rime 仍使用原生分页。
- 返回输入框时重建键盘表面，确保字号与高对比度设置立即生效。
- 横屏使用非全屏输入、54dp 按键行、44dp 工具栏与 48dp 候选栏，隐藏独立模式行，避免默认全屏模式拒绝隐式弹出以及过多垂直占用。

## 验收入口

```bash
source tools/android-env.sh
cd platform/android-ime
./gradlew --no-daemon --max-workers=2 :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug
```

安装 App APK 和 AndroidTest APK 后：

```bash
adb shell am instrument -w -e requireNativeRime true -e runKeyboardUi true \
  dev.shurufa.ime.test/androidx.test.runner.AndroidJUnitRunner
adb shell am instrument -w -e requireNativeRime true -e runKeyboardUi true -e visualProfile large \
  dev.shurufa.ime.test/androidx.test.runner.AndroidJUnitRunner
```

`large` 组合特大字号、左手模式、高对比度；测试完成后恢复原偏好和默认输入法。
测试截图存放在目标 App 的 external files `keyboard-visual` 目录，包括字母、数字、九键、展开候选、符号页。
测试失败不计为通过；小屏、系统大字体、横屏与 TalkBack 的覆盖情况以实际执行记录为准。
