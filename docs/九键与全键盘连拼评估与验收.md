## 实际引擎与能力

Android 9 键使用 `pinyin.reference`；Android 26 键在原生 Rime 可用且允许学习、非密码场景下使用 Rime，否则回退到自研核心。不能把 9 键的局限直接套用到 26 键，也不能仅凭方案文件宣称实际安装包已通过测试。

| 项目 | 9 键、自研核心 | 26 键、Rime |
| --- | --- | --- |
| 全拼词语 | 数字编码检索、读音消歧 | 完整拼音检索 |
| 简拼与混输 | 多音节词首数字、全拼数字混输 | 首字母及 zh/ch/sh 声母简拼 |
| 手动分词 | 分词键、单引号边界约束 | 分词键、Rime 音节边界 |
| 多词组合 | 本轮新增有界词典搜索 | 方案已启用 `enable_sentence` |
| 个人学习 | 选字、选词及完成后的自组词 | Rime 用户词典 |
| 待选输入 | 仅在键盘内显示，不向应用写入编码 | 仅在键盘内显示拼音 |
| 手机上回车 | 有组合时选当前候选，不提交数字编码 | 保持现有原拼音提交约定 |

26 键不是英语键盘直接输出字母的同一种模式。中文模式下空格选汉字，英文模式下直接输入字母。`lvdai` 使用 v 表示 ü；目前没有承诺所有输入法都支持的模糊拼音、滑行输入或拼写纠错。

## 本轮实现

1. 取消核心原有“普通候选 50 个、逐字回退时普通候选仅 20 个”的永久截断。保留完整排序结果，按 100 个一批输出，通过 `CandidatePage` 和 PageUp/PageDown 获取后续结果。Android 展开面板先翻当前批次内的可视页，再请求下一批次。全部候选指词典检索/逐字候选，不代表穷举所有可能句子。
2. 多词组合使用最多 12 条路径的 beam search，每段最多保留 4 个词典候选，最多输出 5 个组合结果。支持完整编码、明确分词边界及首音节筛选，必须消耗完整输入才能成为整句候选。
3. 搜索仅用于 4～64 字节的有效输入，每个词最长消耗 24 字节，限制组合量。超出范围仍可检索原有词条及逐字选词，不截断用户输入。
4. 评分基于词频、个人词频和组合段数惩罚；精确词条仍优先。它不是上下文语言模型，没有语义正确性保证；简拼整句搜索也没有实现，已有词条的简拼能力不变。
5. 整句选中后才记录学习数据。未选候选不学习，密码/禁止学习范围仍遵循核心隐私策略。
6. Android 9 键空格与回车选择当前显示候选；无候选时保留输入并提示调整，不把数字编码当正文上屏。26 键和桌面端原拼音回车约定不变。
7. 9 键提示改为基于输入前缀的读音选项；不再随首候选排名猜测读音，也不显示“拼音＋残余数字”。完整候选读音仍显示在候选注释中。

## 尚未完成的高级能力

- 在未上屏长串的任意音节位置直接修改/锁定读音；目前仍是首音节消歧、手动分词、逐字选择或退格重输。
- 上下文语言模型、多词简拼整句搜索、自动拼写纠错。
- 已上屏误选的安全撤销及学习回退，需要结合编辑器状态验证，不能只减一个词频。
- 实体手机上的首选命中率、前五覆盖率、长句选词次数与端到端 P95/P99。桌面计时和模拟器回归不能替代这些数据。

这些项目不能因已有“组合搜索”就标记完成，也不应仅继续扩词库来掩盖解码限制。

## 验收入口

```bash
cargo test -p ime-engine-pinyin -p ime-engine-rime -p ime-ffi --lib
cargo test -p ime-engine-pinyin --release abbreviation_lookup_latency -- --ignored --nocapture
adb shell am instrument -w -e class dev.zhimo.ime.PinyinContinuousInputTest,dev.zhimo.ime.OrderedNativeInputTest dev.zhimo.ime.test/androidx.test.runner.AndroidJUnitRunner
adb shell am instrument -w -e class dev.zhimo.ime.KeyboardInteractionTest -e runKeyboardUi true dev.zhimo.ime.test/androidx.test.runner.AndroidJUnitRunner
```

Android 测试只在专用模拟器执行：键盘测试会临时切换默认输入法并恢复；原生连拼测试使用隔离的词频和 Rime 用户目录。

重点断言：履带、物联网、你好中国、简拼、手动分词；组合必须覆盖完整输入；候选翻页无遗漏；翻页后空格选择当前页；重置后不能重用旧候选；快速输入不能丢字、重复或乱序。
