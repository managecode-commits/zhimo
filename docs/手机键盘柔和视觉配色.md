# 手机键盘柔和视觉配色

Copyright © 2026 立方田 <managecode@gmail.com>

## 2026-09-14 调整

原普通模式按键和候选字为纯黑，字符键使用中等字重，明暗反差偏强。本次采用柔和深灰而不是降低文字透明度，保留字号、键距、触摸区域和所有输入行为。

| 元素 | 浅色模式 | 深色模式 |
| --- | --- | --- |
| 主文字及图标 | `#363D48` | `#E5E8EE` |
| 字符键、空格底色 | `#FAFAFC` | `#383E47` |
| 功能键底色 | `#D2D7E0` | `#454B55` |
| 按下、选中底色 | `#C5D5F0` | `#465C80` |
| 辅助字符 | `#59616E` | `#BDC2CC` |

浅色键盘和候选栏统一为 `#E3E5EB`，避免候选栏白色块产生割裂。普通字符采用常规字重；主要操作键保持中等字重。圆角由 7dp 改为 9dp，实心按键使用 1dp 低对比描边，不添加厚阴影。透明工具页签不加边框。高对比度模式保留黑白与黄色选中状态。

按 sRGB 相对亮度计算，浅色主文字在字符键、功能键、按下背景上的对比度分别约为 10.50:1、7.58:1、7.38:1；深色主文字在字符键和按下背景上分别约为 8.78:1、5.51:1。这些数值仅验证配色可读性，不代替实机视觉验收。

安装后需检查 26 键、9 键、数字、符号、表情、手写及横屏模式；检查深色主题、高对比度、大字体、长按提示及候选选中效果。手写识别算法与用于识别的图像笔迹颜色不在本次修改范围内。
