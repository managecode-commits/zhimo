# 不限格连写与手动分字

后续候选排序与逐字纠正更新见 [连写候选排序与逐字纠正](连写候选排序与逐字纠正.md)。下文交错展示方案为历史实现，最新版本优先展示主字数完整词组。

日期：2026-09-14。修复用户截图中“长横跨过三等分线，整次识别被拒绝”的问题。

## 使用方式

默认离线字形识别仍开启，手写默认为“自由连写”。画板不再显示固定三格，从左到右书写 1 至 4 字即可；不按停顿切字，不自动上屏。候选包含不同分字方案的结果，可横向浏览或展开更多候选。

分字不合适时：

1. 点击“调整分字”，以当前笔迹的空间关系建议初始字界。
2. 在字与字的空隙点一下添加字界；拖动已有竖线调整位置；点一下已有竖线删除它，从而合并两侧笔迹。最多三条字界，删除全部字界代表整幅笔迹按一个字识别。
3. 点击“完成分字”重新识别，再点选候选或“整句上屏”。

“自动分字”取消手动字界并重新尝试自动方案。调整过程中不会把触摸当成新笔画，也不会提交首候选。清空会同时清除笔迹与手动字界；撤笔保留其余笔迹；提交失败保留笔迹。重新加载不可用模型时不再先清空画板。

用户已明确关闭过字形开关时仍保留其选择；可以在设置中开启后重新打开手写。单字模式、共用候选/工具顶栏及拼音功能继续保留。

## 实现

- 移除固定三等分坐标和跨线即拒绝条件。
- 按每笔横向范围的连通关系生成优先分字方案，并增加合并或不同数量分字的替代方案；每次最多四个方案，每个最多四字。
- 每笔始终完整保留，不裁掉跨界横笔。手动字界按整笔横向包围框中心归属分组，字界可以越过笔画，不会因此报错。
- 每个方案复用原离线单字识别器，缓存相同笔画集合的识别结果；不同方案的候选交错展示，最多 100 项。一个方案失败不会抹掉其他方案的有效结果。
- 建议字界从用户点击调整时的当前笔迹计算，避免用仍在推理的旧快照。调整、撤笔、重写、清空和关闭后的旧结果仍受版本校验隔离。

这仍是空间启发式分字＋单字识别，不是新训练的整行识别模型，没有语言模型语义纠错或校准的整句置信度。左右结构字可能被猜成两个字，因此保留合并方案与手动纠正。若一整笔真的连接了两个不同汉字，目前不会沿笔画切断，该类写法仍可能需要断笔重写。不能将“移除固定格限制”等同于任意连笔都能准确识别。

## 验证范围

新增合成几何测试，覆盖两组宽字跨越旧三等分线、整笔保留、合并方案、手动字界、非法字界、备选方案容错和关闭后的迟到结果。实际设备流程使用横向两条宽横线，覆盖自动候选、添加/删除/拖动字界、调整期间禁止提交、完成分字后整句“一一”上屏。

用户原图没有目标字标注和原始触摸轨迹。合成几何用例证明不再因旧格线拒绝，并不证明截图中的实际字已经识别正确；真实书写准确率、复杂连笔、左右结构字和 ARM 真机性能仍需独立验收。用户原图没有被修改、上传或随包分发。
