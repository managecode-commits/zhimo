# Android 常用表情输入

后续已加入第一层入口、轻量样式、固定高度滚动面板及清除确认；最新安装包与操作见
[键盘视觉与一级表情入口](键盘视觉与一级表情入口.md)。以下保留初版交付记录。

本轮扩展内置 Unicode Emoji 表情页，不是微信图片贴纸或 GIF 表情包。
无需联网、下载素材或新增权限；显示样式取决于系统及接收应用的字体支持。

## 入口与功能

- 点击键盘 `#+=` → `😊`；有候选时也可从 `工具` → `表情` 进入。
- 常用、心情、手势、生活四类，每类 24 个按钮（类别间有重复），每行六个，字号 28sp。
- 最近：按最近选用顺序保留最多 24 个，去重并保留完整 Emoji 序列；只有应用确认接收输入后才记录。
- 清最近：删除本机表情最近记录，不影响拼音词库、手写设置。
- 密码输入框、关闭个性化学习或编辑器要求不学习时，不读取或写入最近记录。
- 切换表情模式沿用现有组合输入确认保护；未确认手写不会因切换而直接丢弃。

输入的是文本，不自动点击聊天软件的发送按钮。图片贴纸需另行设计素材来源、许可、分享和目标应用兼容流程。

测试覆盖类别容量、重复/非法记录过滤、最近顺序与上限、多码点表情完整保存。
