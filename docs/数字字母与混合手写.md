# 数字、字母与混合手写

## 使用

手写区域左上角的范围按钮按「混合 → 中文 → 数字 → 字母」循环切换。默认开启离线字形模型时使用混合模式；已明确关闭该模型时，初始仍使用原中文轨迹识别。用户主动切换到数字、字母或混合范围时，该次面板使用内置离线字形模型，不需要下载。

- 混合：汉字、ASCII 数字 0–9、英文字母 A–Z / a–z。
- 中文：只显示汉字候选。
- 数字：只显示 0–9，避免字母 O/I 等抢占候选。
- 字母：保留大小写，不将 a 自动变为 A，也不把 l/I 自动变为 1。

切换范围保留笔迹和手动字界，并重新识别；旧范围的异步结果与旧候选按钮失效。单字、1–4 字横向连写和逐字纠正均使用同一范围规则，替换候选不会提前上屏。扩展拉丁字母、全角字母、标点及任意长度英文连笔不在此次范围内。

## 实现边界

原实现按 Unicode Han 属性丢弃所有数字和字母。本次将范围过滤放在模型候选截断之前，同时贯通连写组合和逐字纠正，避免后续再次丢弃有效字符。不引入网络请求，不修改模型权重或第三方授权。

本次不等于所有人的手写 62 个数字/大小写字母均达到可靠准确率。0/O、1/I/l、2/Z 等字形存在歧义，混合模式仍可能排错；优先切换到数字或字母范围，必要时逐字选择。范围限定也不构成置信度校准。真实笔迹独立测试仍是发布验收条件。

本轮只扩展 Android 字形识别与键盘 UI；Linux 原中文轨迹面板及其他平台尚未新增数字/字母手写引擎，不宣称跨平台功能同时落地。
