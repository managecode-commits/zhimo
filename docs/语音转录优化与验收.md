# 语音转录优化与验收（2026-09-14）

本文保留原 Whisper 实施记录；桌面继续使用该链路。2026-09-21 后续变更：Android 版本码 5 起移除 Whisper，改为流式模型和按住说话、松开结束并直接上屏，见[最新手机端说明](Android流式语音与按住说话.md)；下文的手机确认面板、热词和 VAD 设置不再适用于新版。

## 实施范围与真实边界

本轮改进 Android 内置语音与跨平台共享推理库，不代表 Windows/Linux/macOS/iOS/鸿蒙麦克风输入已全部完成。
仍为最长 60 秒录音、停止后批量转录；未实现实时中间文本或录音期间自动静音结束。

## 已实现

- 私有模型首次使用完整 SHA-256 校验；同一进程内路径、长度、修改时间未变时复用验证结果。重启后重新校验。此缓存不用于防御已能修改应用私有文件并伪造元数据的攻击者。
- 共享推理库保留一个模型上下文，串行推理、忙碌时返回 BUSY；`no_context=true` 避免把前次转录作为下次上下文。Android 完成任务后闲置约 30 秒释放，内存压力、服务关闭时也释放。模型加载本身仍不能即时中断。
- VAD 预处理也不是即时可中断阶段；120 秒截止通过阶段检查和推理回调执行，不是强制终止线程的硬时限。取消后由任务身份校验阻止迟到文字上屏。
- 内置 Silero VAD v5.1.2，885,098 字节；录音结束后用神经网络检测人声片段。保留关闭选项，便于轻声误过滤时恢复。不是仅靠能量阈值，更不等于自动断句或完整降噪。
- 准备模型、录音、转录分开提示；录音显示秒数及音量提示。音量提示仅依据能量，不声称实时检测到人声。
- 默认确认后上屏；确认面板可取消、重录、删除末字。切换/关闭输入框或移动宿主光标时丢弃待确认文本，不写入其他输入框。尚无自由编辑或词级纠错学习。
- 设置可关闭确认以恢复直接上屏。中文简体转换使用 Android 10+ 系统 ICU；Android 8/9 保留原文，不假称完成繁简转换。不把“一百”强制改成“100”，不猜姓名，不移除英文单词间空格。
- 可保存最多 16 个个人热词，每词最多 24 个字符，作为本地模型初始提示，不作强制替换。禁止个性化学习的输入域不传个人热词。不自动读取聊天内容、联系人或剪贴板。
- 系统语音请求及结果语言明确跟随中文/英文键盘；保留独立联网授权和不静默回退原则。
- JNI 按错误码显示中文提示，区分忙碌、取消、超时、模型及资源错误；补充工作线程引擎版本不匹配与内存不足处理。

共享 ABI 保留 `zhimo_speech_transcribe`，新增 `zhimo_speech_transcribe_options`（提示词/VAD）与 `zhimo_speech_trim_cache`。桌面调用者须自己决定闲置清理时机。平台可复用推理、模型描述、错误码、取消契约，但采音权限和输入会话仍需分别接入。

## 可复现验收

```bash
python3 tools/test-evaluate-speech.py
python3 tools/prepare-speech-eval-fixtures.py
python3 tools/evaluate-speech.py \
  --dataset target/speech-eval-fixtures/samples.jsonl \
  --library target/shared-speech/libzhimo_speech.so \
  --model models/speech/ggml-base-q5_1.bin \
  --vad models/speech/ggml-silero-v5.1.2.bin
```

生成数据仅包含静音、440Hz 纯音以及上游 JFK 公开样例的引用，不采集麦克风或上传音频。参考文本来自固定 whisper.cpp v1.9.1 测试文件。报告默认不输出转录原文。

自建 JSONL 每行需要 `id`、`audio`（相对数据集路径或绝对路径）、`reference`（人工核对）、`language`（zh/en）、`category`。音频限已授权的 PCM16/16kHz/单声道/0.1–60 秒。程序拒绝无参考字段、重复 ID 和错误格式。

指标：中文字符错误率 CER、英文词错误率 WER、无参考文字音频的误插入数、失败数、调用耗时 p50/p95、每条 RTF。归一化采用 NFKC、忽略标点、英文大小写不敏感，但不合并繁简或数字写法。失败任务按空输出计算删除，并独立显示失败数，不能静默排除失败后汇报准确率。

同一进程首个非静音样本包含冷加载，后续样本可能复用模型；比较模型必须使用同样的样本顺序、设备、线程、温度及 VAD 设置。评测工具不自动下载替代模型，不以模型体积推断准确率。

## 后续不能标为完成的项目

1. 多说话人普通话、口音、中英混说、真实噪声、地名和数字参考集，以及低/中/高档 ARM 真机 CER/WER、峰值内存、温升、耗电、蓝牙麦克风、来电中断测试。需获得授权录音、人工参考文本和设备。
2. 自由编辑、词级纠错记忆；需要将用户明确确认的修正与原识别结果配对，并遵守隐私开关。不应把整句聊天内容默认保存到热词。
3. 更换默认 ASR 模型；需在相同测试集上比较后决定，不在缺乏测量时增加数百 MB 模型。
4. 实时分段预览和自动端点；需有界音频队列、稳定前缀/可变尾部、重叠去重及取消测试。不能把逐段文本直接反复写入宿主输入框。
5. Windows/Linux/macOS/鸿蒙系统麦克风到输入会话接入；iOS 容器端侧听写与键盘结果交接。须各自原生 SDK、签名/安装及系统输入环境验证。

- 共享库与 VAD 组合：公开英文、中文推理及运行中取消均通过。这里只证明链路可用，不代表中文准确率已测。
- 独立评测器：生成的静音与 440Hz 纯音均未输出文字；JFK 单条 22 词参考文本 WER 为 0。仅这一条公开英文样例，不能推广为整体准确率。
