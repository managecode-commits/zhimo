## 本轮整改

| 问题 | 实现与验收方式 |
|---|---|
| 标点、模式切换丢失组合输入 | 先提交引擎首选，再提交标点或切换；提交失败保留输入；Debug 专用编辑器 + 真正点击 IME 的 opt-in instrumentation |
| `re` / `ren` 被“认为”抢占首选 | 完整匹配作为独立排序层，优先于词频和学习分；新增回归测试 |
| 九键预编辑与光标不一致 | 编辑区保留真实数字串，候选注释显示拼音；不以猜测出的完整词替代尚未输入内容 |
| 每键遍历全词库 | 全拼与 T9 各建立一次排序索引，以二分定位前缀范围；与全表匹配结果做等价性测试 |
| Rime 展开只显示首个原生页 | 公共 Key 增加 PageUp/PageDown；Action 增加 CandidatePage；C ABI 1.2 增加命令 6/7，Android 原生翻页与本地数组分页分开处理 |
| Rime 隐私开关无效 | Adapter 在禁止学习/密码上下文中拒绝输入并清理组合；Android 自动选择遵守学习策略的参考引擎，绝不声称 Rime 用户词典已经支持动态禁学 |
| 连续删除离开键盘仍有定时任务风险 | 重建键盘与结束输入时取消任务；密码框不显示按键预览 |
| 语音迟到回调污染下一会话 | 每次创建独立识别器，用实例身份与有效状态过滤回调；捕获识别器创建失败 |
| iOS 基本编辑行为不完整 | 补组合显示、中英切换、空组合时编辑器退格/空格；仅源码整改，需 Xcode 验证 |

## 兼容契约

- `CandidatePage { index, has_next }` 的 index 从 0 开始，表示原生候选页，不是 UI 自己切出的数组页。
- 新候选页返回新的 `ShowCandidates`；`rime:N` 仅属于当时的原生页，不可缓存后跨页选词。
- C ABI action kind 6 对应上述 JSON 元数据；旧端必须忽略未知 Action。命令 6/7 在不支持原生分页的引擎中可以被忽略。
- 九键仍是参考引擎，二十六键可用 Rime。二者学习存储尚未合并：SQLite 学习记录不包括 Rime 用户词典，通用数据导出不能宣称导出了全部中文学习数据。
- 禁学 Rime 返回错误是 fail-closed 安全边界，不是完整的原生隐私方案；接入方必须降级到策略安全引擎或透传，不能吞掉输入错误。

## 复现命令

```bash
./tools/verify.sh
cargo run --offline -p ime-cli -- pinyin re
cargo run --offline -p ime-cli -- pinyin ren
cargo run --offline --release -p ime-bench -- 1000
ANDROID_RIME_ROOT="$PWD/target/android-rime" ./tools/verify-android-beta.sh

# 仅在专用测试设备上运行：临时启用/切换 IME，并在 finally 恢复原设置。
source tools/android-env.sh
cd platform/android-ime
./gradlew --no-daemon :app:connectedDebugAndroidTest \
  -Pandroid.testInstrumentationRunnerArguments.requireNativeRime=true \
  -Pandroid.testInstrumentationRunnerArguments.runKeyboardUi=true
```

新 UI 测试不能替代完整验收矩阵：目前只覆盖拼音后标点、模式切换及数字键提交。九键全键、长按手势、旋转、无障碍、语音真音频仍需补测。

## 产品与底座未完成项

1. 键盘状态机尚未从 Android Service 完整拆出；统一布局清单、能力协商与共享语种行为测试仍待实现。
2. 九键/二十六键的整句能力和学习数据一致性仍待设计与实现；拼音质量需大规模语料评测，不能用词条数替代质量。
3. 语言包下载、原子安装/升级/回滚，以及平台密钥存储、账户恢复和正式同步服务仍待实现。
4. macOS/iOS 完整 Xcode 工程、macOS 候选窗及实际平台功能仍有开发工作，不能归结为只缺签名。
5. Windows TSF、Fcitx 5 需真实系统加载与应用兼容验收；桌面麦克风服务和统一语音产品尚未完成。
6. Android 需 ARM 真机、各编辑器、旋转/大字体/TalkBack/长期使用矩阵，以及发布签名。

验收原则：源码存在、编译成功、模拟器通过、真机通过、正式发行是不同阶段。只有实际完成的阶段才可标记完成；本轮整改不等于五平台最终产品全部完成。
