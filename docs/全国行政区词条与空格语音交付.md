# 全国行政区词条与空格语音

## 全国行政区名称词条

本次生成 6,632 条地名/拼音组合，含 3,389 个去重后的来源全称及简繁变体，另提供简称和重名地区上级限定词。
“河北省/河北”“石家庄市/石家庄”“北京市朝阳区”等均可输入。
统计是输入词条覆盖数量，不是官方行政区数量；同名词去重，港澳台层级不强行套用大陆地级/县级概念。

主快照覆盖 34 个省级名称、333 条大陆地级记录、2,813 条大陆县级记录；另补充 32 条省直辖县级记录。
港澳台补充保留来源中的城市、区域、县及区名，包括台湾 9 个城市及 13 个县名记录；不新增乡镇村级名录。
香港无“区”字的来源标签补充区名全称，简称保留；“市辖区”“省辖县”等联动占位词不入词库。

### 来源与边界

- 主数据固定于 [Chen-Yuanmeng/China-Administrative-Divisions 的 2026-03-15 提交](https://github.com/Chen-Yuanmeng/China-Administrative-Divisions/tree/a189d17addb29a568335df46c79f5a6a3c02d4f3)，数据 CC0-1.0。
  上游说明大陆数据来自民政部国家地名信息库，港澳台数据为多来源人工整理；不是所有地区统一日期的官方名录。
- 对主数据漏掉的济源、神农架、石河子、白杨等 32 个省直辖县级单位，采用
  [modood 固定快照](https://github.com/modood/Administrative-divisions-of-China/tree/c49d495b40ac73eb1a66f6eeae5f8fd10696f035) 补齐，WTFPL-2.0。
  不整批并入旧开发区统计记录，避免把历史区划当作现行记录。
- 两江新区名称及代码可对照 [重庆市民政局公告](https://mzj.cq.gov.cn/zwgk_218/zfxxgkml/tzgg/202512/t20251205_15215632.html)。
- 拼音由固定版本 pypinyin 0.55.0 生成，繁简转换采用 opencc-python-reimplemented 0.1.7。
  增加 24 条地名专用多音字规则，覆盖单县、繁峙、荥经、浚县、涡阳、中牟、珲春、宕昌等。
  荥阳/荥经读音差异可参见 [郑州地名网](https://mzj.zhengzhou.gov.cn/work/9569462.jhtml)。
  不修改通用单字读音，也不声称所有地名已经逐项人工审音。

原始数据、许可证和 SHA-256 固定在 `crates/ime-engine-pinyin/data/geography/`；
生成清单为 `manifest.json`，不能将其描述为 2026-09-14 实时官方全量区划。
后续行政区划变化需更新快照、审查差异并重新生成，运行时不联网获取词库。

### 接入与复现

同一份数据生成共享 Rust 引擎的 `geography_lexicon.tsv` 和 Rime 的 `zhimo_geography.dict.yaml`，
支持 26 键全拼、手动分词与 9 键查询。词条采用低于原常用高频词的初始权重，用户学习排序仍生效。
Android Rime 资源版本由 4 升为 5，覆盖安装时更新共享词库，不清除用户学习目录。

在独立 Python 环境安装 `pypinyin==0.55.0` 和 `opencc-python-reimplemented==0.1.7` 后执行：

```bash
python3 tools/update-geography-lexicon.py --write
python3 tools/update-geography-lexicon.py
python3 tools/test-geography-lexicon.py
cargo test --workspace
```

本机依赖解包于忽略目录 `target/geography-python`，对应命令可加 `PYTHONPATH=target/geography-python`。
默认检查模式不改文件；普通构建使用已提交生成词库，无需安装这两个 Python 包。

## 顶栏左右切换与空格语音

- 移除顶栏麦克风入口，原位恢复“居中 → 左手 → 右手 → 居中”切换；一级 Emoji 入口保留。
- 26 键、9 键、手写、数字、符号和表情页统一在空格键显示“长按语音”。符号页底栏重复的数字入口改为空格，数字仍可从顶栏进入。
- 空闲轻点仍为空格或选词；长按开始录音，松手后继续录音；轻点“停止”结束录音并转录，识别中轻点“取消”丢弃本次结果。
- 正在组拼音或存在未确认手写时，长按只提示先完成输入，不自动提交、清空或改写当前候选。
- 麦克风权限、密码框保护、离线模型与系统语音联网设置沿用原策略。
  系统语音的“停止”调用 `stopListening()`，不是取消识别。
