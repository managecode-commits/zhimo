## 使用方式

1. 打开手写面板，点击底部“单字”，切换为“停顿叠写”。
2. 在画板中写一个字，等待候选出现。默认最后一笔结束后停顿至少 1.8 秒，再在同一位置落笔，上一字首候选进入草稿、画板清空，新笔属于下一字。
3. 也可点击候选指定这一字，或点“下一字”暂存首候选，无需等停顿。点击“停顿1.8秒”可循环选择 2.4 秒、手动分字、1.2 秒、1.8 秒。慢写建议选择手动分字。
4. 草稿横向排列，点击某字可从该字的候选列表重新选择。没有合适候选时，先撤回末尾字再补笔或重写。
5. 点击“整句上屏”或空格/回车，将草稿和当前已识别字一起提交。长按空格在存在草稿时也先确认文字，不立即启动语音。

有笔迹时删除/撤笔优先撤当前字最后一笔；当前画板为空、草稿非空时，恢复末尾字的笔迹用于修改；两者均空时，删除键才删除编辑器文字。清空清除当前笔迹及全部未提交草稿，不删除已上屏文字。

没有候选或识别失败时，不强制分字、不清空笔迹。提交失败时保留草稿。用户通过面板切换数字、拼音、符号或单字模式时，若有未提交内容，会提示先上屏或清空。

## 实现与边界

这是**停顿分字、单字识别、草稿拼接**的离线叠写模式，不是将多字混合轨迹直接送入多字模型，也不是任意连笔且无需停顿的自由叠写。书写一个字中间停顿过长，下一笔可能被划为下一字；请调长停顿或使用手动分字。候选未就绪时下一次落笔会被拒绝并提示等待，避免把未识别字直接丢弃。

停顿计时只更新提示，不自动向编辑器提交任何文字；实际自动分字发生在下一次落笔之前。每段保留轨迹、候选及当前选择，最大 32 字；草稿仅存内存，不写文件、不上传。满 32 字时需先上屏或清空，不截断草稿。

继续使用 APK 内的原轨迹识别或实验性字形识别 Provider，无新增模型下载。实验性字形模型仍需在设置开启。单字识别质量没有因为拼接成句而提升，本轮没有语义纠错、词频重排、多字联合解码或个性化训练。

切换输入框、关闭输入法视图、旋转重建或进程销毁会取消内存草稿，防止旧输入框笔迹跨编辑器提交；离开前请先上屏。模式和停顿时长目前只对当前面板有效，重新打开默认单字和 1.8 秒。

涉及 `HandwritingDraft`、`HandwritingPanel`、`HandwritingCanvas` 和 Android 输入法页面切换保护。未修改通用 Rust/C ABI 和其他平台。
