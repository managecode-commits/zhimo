# 连拼学习与个人词库

本文说明 Android 统一拼音模式的学习行为与操作边界。新版默认让九键和 26 键共用自研引擎与本地个人词库，新选出的连拼词可在两种布局之间复用；旧 Rime 历史词库保留，但未自动转换或合并。

## 缺词时如何输入

输入完整拼音后，先查看整词和自动组句候选；不合适时逐字选择，直到剩余拼音全部完成。引擎记录各次选字，以及这次完整组合对应的新词。首次完成新的多段组词或自动组句时，键盘提示“已记住新词”。中途取消的组合不会作为完整词记住，已经确认的单字仍可有学习记录。

例如在同一次组合中输入 `maolvbei` 并选择“猫”“驴”“杯”，以后可用 `maolvbei`、`mao'lv'bei` 或九键 `62658234` 查找“猫驴杯”。这是测试样例，不是内置常用词。分别在三个独立组合中输入三个字，不保证自动连接成词。

## 查看和纠正学习记录

- 在中文拼音模式打开键盘工具，选择“个人词库”，分页查看文字、拼音和学习分。列表反映正向学习分，不显示已删除或降至非正分的记录。
- 点击列表中的词，或者长按拼音候选，可降低学习优先级或删除学习记录。操作作用于该词已记录的不同拼写，不限当前九键或全拼输入。
- 删除学习记录不会删除系统词条，也不是永久屏蔽；系统词或自动组句仍可能产生相同文字，之后主动选择也可重新学习。
- 降低优先级每次减少一个学习分；不承诺一次操作后候选完全消失。没有可修改记录时会明确提示。
- “撤销上次学习”撤销当前会话最近一次选词学习；连续逐字组词视作同一学习事务。它不会删除或改写应用输入框里的文字，只能撤销一次，不能代替编辑器撤销。

修改后正在显示的拼音候选会重新计算。管理写入在工作线程进行；保存失败会提示检查存储空间，不能把失败当作已落盘成功。

## 引擎和隐私边界

设置中的“统一拼音学习”默认开启。关闭后，26 键可恢复旧 Rime 兼容模式；九键仍使用自研引擎。更改后重新打开键盘生效。兼容模式与统一模式的历史数据不自动互通，旧 Rime 文件不会被本次功能删除。

关闭个性化学习、密码框或应用要求不进行个性化学习时，不提供词库查看和修改入口，底层接口也拒绝相应操作。个人词库仍只保存在本机，不自动上传到云端或其他设备。

## 自动组句的改进与限制

已有音节边界的学习词现在可以作为较长句子的组成部分，而不只匹配整条输入。解码时为学习词建立拼音和九键索引，避免在每个切分位置反复扫描全部学习记录；简拼记录不会被当作完整音节边界。

这仍是有界词典搜索，不是上下文语言模型。自动组句继续保留输入长度最多 64 字符、有限搜索宽度等约束，长句、生僻字与歧义读音不能保证首选正确。手动分词和逐字选择仍是必要的纠正路径。

## 代码与验收入口

- `crates/ime-engine-pinyin`：学习、管理、撤销及学习词参与组句。
- `crates/ime-ffi` 与 `include/zhimo_ime.h`：词库列表、修改、通知及隐私校验接口。
- Android `PlatformPolicy`、`MainActivity`、`ZhimoInputMethodService`：默认引擎、兼容模式及词库界面。
- Rust 回归涵盖拼写别名、删除、撤销、组句和重启持久化；Android `RuntimeSmokeTest` 包含原生接口与隐私测试。

本轮功能纳入 Android `v0.1.1-preview.20260930.1` 预览发布。桌面可复用核心接口，但本轮未增加桌面个人词库管理界面、未编译桌面安装包，也未实现旧 Rime 学习数据迁移。

## 本轮验证结果

2026-09-30 的最终本地 APK 为 `zhimo-v0.1.1-preview.20260930.1-android-debug.apk`，版本码 7，344,903,492 字节，约 329 MiB，使用调试签名。

- Rust 拼音测试 33 项和 FFI 测试 13 项通过；手动性能测试与需专门配置的桌面 Whisper 音频测试各有一项忽略。
- Android 单元测试 28 项、Gradle 构建、Lint、APK 签名和模型及原生库完整性检查通过。
- API 35 x86_64 模拟器在 720×1280、280 DPI 下通过 13 项运行时和界面测试，包含新词持久化、个人词库查看、候选降权、撤销学习不改动编辑器文字及原有按键操作；旧 Rime 兼容链路也参与回归。
- 初次模拟器启动和构建并行时曾崩溃；分开运行后完成验证。无效尾拼测试已修正为“不能吞掉尾拼，但可选择前缀字”；工具菜单入口提前后，最终界面回归通过。

实际手机的输入准确率、长期词库增长后的性能，以及极小逻辑屏幕上的布局仍需要单独验收。
