# 参考键盘布局改版

后续已新增 [多字停顿叠写](多字停顿叠写.md)。本文“多字叠写未实现”和安装包为此前布局改版时的记录；新模式仍不是无停顿自由叠写。

日期：2026-09-13。本次按用户提供的三张参考图调整 Android 输入按键和手写界面，保留现有输入引擎，不把视觉改版描述为识别准确率升级。

## 已实现

| 参考布局 | 本次实现 |
|---|---|
| 26 键 | 浅灰背景、白色字母键、灰色功能键；字母 26sp、居中长按提示；第三行两侧为大小写与删除；底部取消重复删除，加宽空格并放大空格/回车文字 |
| 9 键 | 中央三列字母键，字母 25sp、数字作为次级提示；左侧常用标点，右侧删除、清空拼音、回车；底部符号、中英、宽空格、数字 |
| 手写 | 竖屏默认画板从 200dp 增至 240dp、减淡辅助线；右侧删除和标点；底部宽空格、拼音/英文、数字、符号和回车，空格长按调用现有语音入口 |

字母键使用大写视觉标签，但拼音仍送入小写字母，英文大小写仍由真实状态控制。拼音界面按 Shift 会切换到英文大写，并沿用切换时处理当前拼音的策略。

保留三档字号、深色、高对比度和单手布局。修复高对比度手写画板黑底黑字/黑笔迹的问题。横屏手写不显示侧栏，删除放到底部，标点通过符号页输入；横屏九键左侧使用三个标点以避免把触摸目标压得过小。

## 按键语义与防丢字

- 九键“清空”只取消当前拼音，不删除编辑框中已经提交的文字。
- 手写删除：有笔迹时撤最后一笔，没有笔迹时删除编辑框最后一个完整字素；正在落笔时不执行删除。
- 手写空格/回车：有笔迹且候选就绪时先确认首候选，本次不额外插入空格或发送；下一次无笔迹按键才执行空格或编辑器回车动作。识别未完成或提交失败时保留笔迹。
- 手写空格长按：无笔迹时调用语音；有笔迹时先确认候选，不直接跳走丢失笔迹。
- 侧栏标点：无笔迹时直接输入；有笔迹时提示先选字，保留当前笔迹与候选。
- 保留更多候选网格、最多 100 个候选、撤笔、清空及过期异步结果隔离。

## 能力边界

没有实现参考图中的多字叠写，也没有新增 AI 搜索、聊天等入口。当前仍应一次写一个汉字。

原离线轨迹模型和实验性离线字形模型均随 APK 打包；字形模型仍默认关闭，需要在设置开启“实验性离线字形识别（重新打开手写生效）”。本次未更换模型、未新增个人训练或候选融合，不承诺连笔准确率已经达标。语音入口沿用现有系统识别 Provider，其可用性和离线支持取决于设备，不等同于本次内置了通用离线语音模型。

模型与质量门槛见 [手写字形模型与网格界面](手写字形模型与网格界面.md)。本次仅修改 Android UI；不代表其他四个平台同步完成该界面。

## 构建与验收

```bash
source tools/android-env.sh
cd platform/android-ime
./gradlew :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug
cd ../..
ANDROID_SERIAL=emulator-5554 ./tools/verify-android-handwriting.sh
./tools/verify.sh
```

设备必须是明确授权的专用测试设备，并先安装主 APK 与 androidTest APK。公共底座门禁通过：69 项通过、2 项依赖外部 Whisper 资源的测试忽略，包含格式、Clippy、C ABI 和 TSF 核心探针。Cargo 全局缓存清理出现权限警告，但门禁退出码为 0；未修改用户全局缓存权限。

Android 构建及 Lint 通过，0 错误、4 警告（两个依赖更新提示、两个程序化 View 构造函数提示）。首次回归发现旧测试要求数字字号严格大于字母，已根据新的同级视觉规范改为数字不小于字母，并补充字母至少 26sp、主标签大于提示文字的断言。

API 35 x86_64 专用模拟器在 `Active default network: none` 下更新安装：14 项基础/面板/键盘测试、2 项原轨迹模型测试、1 次原轨迹真实画笔与网格上屏、2 项字形模型/渲染测试、1 次字形真实画笔与网格上屏全部通过，无跳过。额外的大字号＋高对比度＋左侧单手模式真实手写 UI 回归通过。重复 UI 执行不计为新增独立测试方法。

已核对截图：`target/reference-ui-letters.png`、`target/reference-ui-t9.png`、`target/reference-ui-handwriting.png`、`target/reference-ui-handwriting-grid.png`、`target/reference-ui-large-t9.png`、`target/reference-ui-large-handwriting.png`。截图仅含自动化合成文字；用户原始参考图没有修改，也不随 APK 打包。真实 ARM 手机性能、不同系统字体缩放及厂商设备仍需实际安装体验，不能以模拟器替代。

额外尝试设置系统旋转后，UI 测试虽通过，但截图仍为竖屏，因此不计为横屏验收；横屏布局分支仍待真实横屏设备确认，名称带 `landscape` 的本地截图不能作为横屏证据。测试后已恢复原系统输入法、旋转设置以及测试前的网络关闭状态，并关闭本轮启动的专用模拟器。
