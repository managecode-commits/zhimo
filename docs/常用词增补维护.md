## 文件与规则

- 参考引擎：`crates/ime-engine-pinyin/data/curated_phrase_lexicon.tsv`。
- Rime：`platform/android-ime/app/src/main/assets/rime/zhimo_curated.dict.yaml`，由主词典导入；Android 和 Linux 打包均包含此目录。
- 新增词库独立于自动下载的上游词库，不会被上游更新脚本覆盖。
- 权重是项目编辑优先级，不是实测使用频率；不使用强制置顶逻辑，不移除原有同音候选。
- 只编辑 TSV 源文件，更新 Android `rime/version.txt` 和主词典版本后，运行 `python3 tools/sync-curated-lexicon.py` 生成 Rime 文件。不要手动维护两份数据；资源版本变化触发安装后的刷新，不清除用户学习目录。

## 验证

- `python3 tools/sync-curated-lexicon.py --check`：检查生成文件未过期，已接入统一验证入口。
- `cargo test -p ime-engine-pinyin --locked`：检查数据一致性、重复项、全拼、分隔拼音、九键检索及“极简”的简拼候选。
- `tools/verify-linux-rime.py`：通过实际 Rime 检查全拼、简拼候选和选词上屏。
- Android 地理词库测试改为对照随包版本，避免旧的硬编码版本号导致无关测试失败；本轮未运行设备测试。

本次是代码与词库更新。旧安装包不会自动获得这些词条，需要重新编译安装包并升级。
