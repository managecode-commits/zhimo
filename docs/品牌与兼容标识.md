# Zhimo 品牌与兼容标识

项目采用 Zhimo 命名：用户产品为「知墨输入法 / Zhimo IME」，通用输入底座为「Zhimo Core」，语言扩展统称「Zhimo Language Packs」。这仅确定项目品牌，不表示已获得商标、域名或应用商店名称权利；已知公开领域存在同名使用。

## 本次更新范围

- Android：应用、系统输入法列表、设置说明及麦克风权限提示。
- Linux：IBus 静态与动态注册的显示名称、Fcitx 5 输入源与插件显示名称、离线手写窗口标题。
- Windows：TSF 语言配置的显示名称；需重新编译并注册 DLL 后生效。
- Apple：仓库尚无可直接构建的完整 Xcode 应用工程；创建容器、键盘扩展和 macOS 输入法 target 时，将 `CFBundleDisplayName` 设置为 `知墨输入法`（英文本地化为 `Zhimo IME`）。不宣称已经修改或构建不存在的应用工程。
- README 与总体方案采用新品牌；历史验收记录和旧安装包保留原名。

## 兼容性约束

显示名与技术标识分离，本次不迁移以下内容：

- Android `dev.shurufa.ime`、服务类名、SharedPreferences 与学习数据路径。
- Linux 引擎 ID `shurufa`、D-Bus 名、配置文件名、插件库名及安装路径。
- Windows CLSID、Profile GUID、`ShurufaTsf.dll` 与用户数据目录。
- Rust crate 名、C ABI `shurufa_*`、Swift `ShurufaCore` 模块及 XCFramework 文件名。
- 现有 Bundle ID、App Group、签名、仓库目录、远程地址及环境变量。

因此构建命令中的 `shurufa`/`Shurufa` 不是遗漏，不应全局替换。底座品牌 Zhimo Core 暂不意味着二进制模块同步改名。旧安装包不会因源码修改而更名；需安装新构建包。Android 在应用 ID 和签名一致时可覆盖更新，不需卸载，避免丢失已有词库和设置。

未购买域名、注册商标、修改远程仓库或发布应用，也未改动第三方授权与贡献者归属。
