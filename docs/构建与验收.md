# 构建与验收手册

## 当前 Linux 环境

```bash
source "$HOME/.cargo/env"
./tools/verify.sh
python3 -m py_compile platform/linux-ibus/shurufa_ibus.py
bash -n platform/linux-ibus/install-user.sh tools/*.sh
./tools/benchmark-input.sh 20000
```

`verify.sh` 执行格式检查、全 workspace Clippy（warnings 即失败）、全部常规测试、C ABI 动态链接程序和 C++ 平台边界程序。

## 生产中文引擎

构建 librime 1.17.0 及其依赖，把安装前缀传入：

```bash
RIME_ROOT=/opt/librime \
SHURUFA_RIME_TEST_DATA=/opt/rime-data \
./tools/build-librime-adapter.sh
```

命令会同时测试 Rust Adapter 和公开 C ABI；测试必须看到真实中文候选并提交非 ASCII 词典结果。

## 离线语音

构建 whisper.cpp 1.9.1，下载有合法使用权的模型与 PCM16 WAV：

```bash
WHISPER_CPP_BIN=/opt/whisper/bin/whisper-cli \
WHISPER_CPP_MODEL=/opt/models/ggml-tiny.en.bin \
WHISPER_CPP_TEST_WAV=/path/to/authorized.wav \
WHISPER_CPP_LANGUAGE=en \
WHISPER_CPP_EXPECTED=country \
./tools/verify-whisper-cpp.sh
```

## 目标平台闸门

- Android：JDK 17、SDK 37、NDK 28.2、Gradle 9.5、AGP 9.3.2，构建 APK 后在真机启用 IME。
- Windows：Visual Studio/Windows SDK，编译 TSF COM DLL、注册后覆盖 Notepad、Office、浏览器、终端和 UWP/WinUI。
- macOS/iOS：Xcode 与签名账号，构建 InputMethodKit、容器 App 和 Keyboard Extension，在 Intel/Apple Silicon 与真机测试。
- Linux：IBus 已完成真实会话探针；Fcitx 5.1.19 头文件 C++20 严格编译已通过，仍需在具备完整运行时的桌面加载并覆盖 X11、Wayland、GTK、Qt、Electron 和终端。

Android 工程配置已在 AGP 9.3.2/Gradle 9.5/JDK 17 下执行到 SDK 组件解析；NDK 许可证必须由
项目责任人阅读并接受，自动化代理不代为接受。Apple 签名、Windows 驱动/COM 注册和应用商店
账号也属于外部发布权限，不应以源码检查代替。

任何没有目标工具链、签名和真机证据的条目只能标记“源码已实现待验证”，不能进入发布完成口径。
