# 跨平台底座整改交付

本记录区分代码实现、主机测试、目标系统验收和正式发布；不是全平台发布完成声明。
已有 Android 功能不能据此认定 Windows、Linux、Apple、鸿蒙具有相同能力。

## 本轮实现

| 范围 | 实现内容 | 验证边界 |
|---|---|---|
| Windows TSF | 输入状态修改移入获准的 edit session；读取 TSF InputScope；密码/PIN 透传、私密输入禁学习；未知自定义输入框保守透传 | MinGW x64 DLL 编译通过；未在 Windows 宿主实测 |
| Windows 生命周期 | 防止新 context 的 cookie 写入旧 composition；失焦异步清理带版本检查；结束 composition 前解除成员引用以防重入释放；释放候选窗口 | 仍需切焦、编辑锁拒绝及宿主终止 composition 的真实 TSF 验收 |
| Windows 按键/异常 | 左右移动、PageUp/PageDown；UTF-8 应用标识；检查 SetText/SetSelection 返回值；工厂构造异常不穿越 COM | 尚无完整候选鼠标、UI-less、无障碍与 DPI 交互 |
| Linux 交付 | 无桌面副作用的 IBus 暂存工具；最终前缀 XML 转义；拒绝覆盖已有目录；模型与许可证一起暂存 | 已生成真实 release Runtime 负载；不是 deb/rpm，也未切换桌面输入法 |
| 共享离线语音 | `zhimo_speech_*` C ABI 1.0：会话、PCM 检查、模型推理、取消、超时、UTF-8 结果释放；Android JNI 复用相同源码 | Linux 原生库和 Android 构建；不等于其他端已接入录音/上屏 |
| macOS | 核心失败或 Ignored 动作透传；空格走候选确认命令，不再无条件吞键 | 源码修改，未用 Xcode 编译 |
| iOS 容器 | 系统识别必须支持且强制设备端；不支持时明确提示、禁止联网回退；停止后等待尾句；离开页面取消 | 这是系统离线 Speech 接口，不是已打包 Whisper 的 iOS App；未用 Xcode 编译 |

Windows 探针新增 12 项编译期隐私映射断言，但不是模拟 COM 的编辑锁单元测试。
文档插入失败后的 Runtime 学习与宿主编辑尚无跨系统原子回滚保证；不能把上述修复称为完整事务系统。

## 本轮验证

- `bash tools/verify.sh`：Rust 格式、Clippy、69 项常规测试通过，2 项外部依赖测试忽略；C ABI 和 C++ 核心边界通过；新增 Linux 暂存测试 2 项通过。
- Windows：MinGW x64 严格编译、链接成功；产物在 `target/windows-tsf-hardening/`。该目录是交叉编译证据，不是签名安装包，未验证目标机依赖分发。
- Linux 共享语音：CMake Release 构建、CTest 边界测试通过。公共英文样本识别含 country，中文样本输出汉字；取消测试通过。本机分别约 7.9 秒和 8.3 秒，不是手机延迟指标或 CER/WER 评测。
- Android：抽离后 Debug APK、AndroidTest APK 构建成功；Lint 0 错误、13 警告。设备回归与最终包检查结果见下方追加记录。
- CI 增加共享语音构建/边界测试，并让 Windows job 执行核心探针。这是工作流配置变更，本轮没有推送或声称 GitHub Actions 已运行。

本机 Cargo 有历史缓存自动清理权限警告，但门禁退出码为 0；本轮未更改用户缓存权限。

## 构建与复现

Linux IBus：

```bash
cargo build --release -p ime-ffi
python3 tools/stage-linux-ibus.py target/ibus-stage --library target/release/libime_ffi.so
```

暂存目录必须不存在，内容使用 `/usr/share` 布局；`--prefix` 表示最终安装前缀，不是暂存路径。
工具不会安装、执行 IBus restart、改默认输入法或自动提供生产级 Rime。
本轮实际输出为 `target/zhimo-ibus-hardening/`。

共享语音构建、调用生命周期和公共样本回归见
[shared-speech README](../platform/shared-speech/README.md)。
所有端原有构建入口见 [构建与验收](构建与验收.md)。

### 最终 Android 回归与安装包

API 35 x86_64 模拟器在 Wi-Fi/移动数据均关闭时完成：离线语音测试套件实际执行 5 项，
其中麦克风用例初次因未启用而跳过；随后单独启用并通过该用例，因此 6 个不同用例均已执行通过。
覆盖模型损坏修复、数字静音、非法 PCM/预取消、运行中取消、真实中英文样本和麦克风结束/取消。
本轮没有重跑所有键盘和手写 UI 用例，不应复用历史全量测试结果替代本次证据。
JNI 中英文样本耗时约 20.4 秒、22.3 秒；模拟器结果不是手机性能承诺。

## 尚未完成的产品工作

以下不是仅缺签名即可完成的项目，仍有开发工作：

1. Windows：完整候选点击/导航、UI-less、辅助功能、每屏 DPI、生产 Rime 配置与安装升级卸载包；真正 TSF 编辑锁/失败注入测试。
2. Linux：统一设置与模型管理器；IBus/Fcitx5 实际桌面矩阵；桌面图像/多字手写；录音界面、语音服务及安全上屏。
3. 跨端服务：共享推理库之外的隔离进程、带身份与焦点版本的 IPC、受限宿主支持、限流/超时/崩溃恢复；不能直接把大模型加载进所有应用的 IME 进程。
4. Apple：可签名的 macOS/iOS 原生工程、完整键盘/候选 UI、容器与扩展通信及资源限制验证；共享语音库尚未在 Apple 目标构建。
5. 鸿蒙：尚无可安装工程。需原生输入法扩展、ArkUI、Native/Rust 适配、资源打包与受限运行模式的权限验证；Android APK 不作为原生支持交付。
6. 全平台：正式签名、自动更新、可访问性、长稳测试，以及授权中文手写/语音评测集和冻结质量阈值。

## 目标系统验收条件

本机没有可用 Xcode、鸿蒙 `hdc`/`hvigor` 工具，也不能运行真实 Windows TSF。
下一阶段需提供可访问的 Windows 测试环境、macOS/Xcode，以及匹配目标系统的鸿蒙 SDK/设备。
签名、商店发布或接受新的第三方许可仍需项目所有者明确授权；本轮未使用任何签名身份发布。

在上述待开发项和目标验收完成前，项目状态应标为“Android 已有可测试 App，跨端底座整改中”，
不能标为“全平台 App 全部完成”。
