# 手写“天／夫”与候选扩展

用户截图：Screenshot_20260914_224231.jpg。写的是“天”，但候选首位为“夫”，第二位为分字结果“十二”。截图仅作为几何参考，未保存或上传原始触摸轨迹；测试笔迹是人工近似重建，不是从截图恢复的真实轨迹。

## 本次改动

- 自由连写不再固定只取两个顶栏候选。单字首选时显示最多五个，多字首选时按可用宽度显示三至五个并保留逐字修改按钮。候选不足时不补假词；极窄屏仍可横向滚动，不压缩到过小触摸区域。
- 单字首选时移除顶栏额外“逐字改”占位，仍可长按具体候选进入纠正；“更多”展开候选网格的操作保持。
- 对四笔、两横、明确撇捺且模型前三候选已出现“天／夫”的笔迹，检查上横长度及撇的起点与上横相对位置。上横下方起撇时优先“天”，明显出头时优先“夫”。接触边界、不确定形态、其他笔画数、数字字母模式保持原排序。
- 只调整这一窄范围易混字，不无条件替换“夫”，不删除原候选；连写分字解释继续保留。单字模式与连写中的单字识别都接入该判断。

## 回归范围

新增 HandwritingShapeRankingTest：截图近似笔迹、真正出头的“夫”、不确定边界、非目标候选、缺笔、字母模式、缩放平移，以及可选的实际图像/轨迹融合模型端到端测试。

HandwritingPanelTest 新增单字首选时五个候选的断言，并保留窄屏逐字修改、取消与过期候选不可上屏测试。仍需用户真机复测原有写法；这不是重新训练模型或整体手写准确率达标的声明。

API 35 模拟器开启 `runRealInk=true`：HandwritingShapeRankingTest、HandwritingPanelTest、FusedHandwritingTest、LineHandwritingTest 共 22 项通过（16.642 秒）。实际图像/轨迹融合与连写链路对截图近似笔迹首选为“天”；不是对用户原始触摸数据的回放。日志为 `target/handwriting-tian-device-tests.log`。
