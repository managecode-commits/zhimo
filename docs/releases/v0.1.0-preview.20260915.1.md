# Zhimo v0.1.0-preview.20260915.1

开发预览版，非正式稳定版本。

## 变化

- 工程命名统一为 Zhimo，补充作者、许可证及构建文档。
- Windows：x64 Windows 上同时支持 x64／x86 TSF；状态栏横竖切换、拖动、隐藏及重复显示修复；离线单字手写与语音面板。
- Linux：Ubuntu 24.04／Debian 12 amd64 的 IBus、Fcitx5 包，单字手写、离线语音、麦克风切换／音量和面板单实例／焦点保护。
- 拼音词库、简拼、本地学习和手写规则持续改进。
- 桌面拼音回车提交原始拼音（`jixu`），空格选择汉字（`继续`）；补充参考引擎、C ABI、IBus 和实际 Rime 回归测试。
- macOS：新增完整脚本构建入口和 IMK／手写／语音源码，尚未在 Mac 编译验收；本版不提供 macOS 安装包。

## 安装

Windows：完整解压 ZIP，在管理员 64 位 PowerShell 中运行 `.\install.cmd -Upgrade`。首次安装不带参数。保存文档并注销登录，清除旧进程中仍加载的 DLL。不要只替换单个文件。

Linux：下载对应发行版的 `zhimo-core` 和现有框架对应的 `zhimo-ibus` 或 `fcitx5-zhimo`，使用 `sudo apt install ./所需包.deb` 安装。不要同时启用两套输入框架。注销登录后添加 Zhimo 输入源。

## 验证与限制

- 本地 Rust 工作区测试通过；Linux 目标容器构建、键盘／IPC／GUI 冒烟、安装／卸载及拼音回归通过。
- Windows 双架构交叉编译及安装脚本模拟检查通过；新增 Win32 状态栏互斥探针在 Windows 安装时执行，本地未执行。
- 不把上述结果视为真实桌面兼容验收。EmEditor 7.00.3、GNOME／KDE Wayland、真实录音设备仍需测试。
- Windows 测试包未签名；SHA-256 仅核对文件完整性，不认证发布者。
- 桌面手写为单字模型，不等同于 Android 双模型／连写。语音为停止录音后的转录，并非实时流式。
- macOS 和 iOS 不属于本次二进制预览的支持范围；Android 本轮不另发旧 APK。
