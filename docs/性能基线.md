# 输入核心性能基线

## 当前版本说明（2026-09-13）

以下 2026-09-02 数值为历史小词库版本，不能作为当前 65,125 条词典版本的验收结果。
整改前本机 Release 单次 1000 轮（6000 事件）P95 为 4.716685 ms、P99 为 6.773833 ms。
整改加入前缀索引后的开发中采样与 Android 构建、模拟器启动并发，存在明显资源竞争，不用来声称性能改善。

完成构建并关闭本轮模拟器后，对当前 Release 程序连续运行三次 `target/release/ime-bench 1000`，每次 6000 事件：

| 轮次 | 总耗时 ms | P50 ms | P95 ms | P99 ms |
|---|---:|---:|---:|---:|
| 1 | 4256 | 0.015711 | 3.438917 | 4.469467 |
| 2 | 4079 | 0.015200 | 3.175571 | 3.879571 |
| 3 | 4405 | 0.016917 | 3.503606 | 4.852868 |

这是当前开发机的可复现热路径采样，不是隔离性能实验；没有关闭其他用户后台服务或固定电源模式，也未覆盖冷启动和 UI。
最终性能验收需补全 T9、短前缀、首次加载、内存峰值和各端按键到显示延迟。

## 历史记录

> 测量日期：2026-09-02；这是 Runtime/参考拼音引擎的内存热路径微基准，不包含操作系统
> 输入法 IPC、窗口渲染、librime 生产词典、磁盘落盘或 ASR。

环境：Linux 7.0 x86_64，Intel Core i7-4702MQ 2.20 GHz，8 逻辑 CPU，release 构建。

命令：

```bash
./tools/benchmark-input.sh 20000
```

本次 20,000 轮 `nihao + cancel` 共处理 120,000 个事件：总耗时 198 ms，约 603,887
事件/秒；P50 1,809 ns、P95 1,925 ns、P99 3,583 ns、最大值 31,112 ns。该结果满足
“核心本地轻量路径 P95 < 10 ms”的架构预算，但发布验收仍必须在每个目标平台测量端到端
按键至候选显示延迟，并以多次运行、固定电源/性能模式和分位数报告替代单次结果。
