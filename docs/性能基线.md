# 输入核心性能基线

> 测量日期：2026-09-02；这是 Runtime/参考拼音引擎的内存热路径微基准，不包含操作系统
> 输入法 IPC、窗口渲染、librime 生产词典、磁盘落盘或 ASR。

环境：Linux 7.0 x86_64，Intel Core i7-4702MQ 2.20 GHz，8 逻辑 CPU，release 构建。

命令：

```bash
./tools/benchmark-input.sh 20000
```

本次 20,000 轮 `nihao + cancel` 共处理 120,000 个事件：总耗时 198 ms，约 603,887
事件/秒；P50 1,809 ns、P95 1,925 ns、P99 3,583 ns、最大值 31,112 ns。该结果满足
“核心本地轻量路径 P95 < 10 ms”的架构预算，但发布验收仍必须在每个目标平台测量端到端
按键至候选显示延迟，并以多次运行、固定电源/性能模式和分位数报告替代单次结果。
