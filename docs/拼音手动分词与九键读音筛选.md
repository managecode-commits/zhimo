# 拼音手动分词与九键读音筛选

## 使用方式

- 26 键：没有拼音时第三排左侧保留原 Shift 功能；有待选拼音时变为“分词”。
  输入 `ji`，点“分词”，再输入 `an`，得到 `ji'an`，可选择“吉安”。
  未手动分词的 `jian` 保持自动解析。分词只修改输入法内部组合，不将字母或分隔符写入应用。
- 9 键：空闲左侧显示常用标点；输入后显示可滚动的读音列表。
  输入 `5426` 可选择 `jian`、`jiao`、`lian`、`liao` 等读音。
  点 `lian` 后重新查询对应汉字，如“连、脸、练”；点读音不会上屏，点汉字或空格才上屏。
- “自动”解除手动读音筛选。退格解除当前读音筛选并删除一个输入字符；清空、选字完成、
  重置和结束会话清除相关状态。连续输入时保留仍适用的首音节筛选。
- 9 键“分词”键继续可用；空输入或已有结尾分隔符时不重复插入。

## 底座行为

Rime 路径使用原生拼音分隔符；自有回退引擎和 9 键路径按词库的音节边界校验手动分词，
不再只删除分隔符后查询。9 键读音列表来自完整单字词库，不从截断后的前 50 个候选反推。
读音筛选在候选截断前执行，也用于空格选词和候选 ID 校验。

新增可选动作 `PinyinReadings { readings, selected }`，C ABI 动作编号为 `7`，
通过已有 JSON 动作接口获取；使用 `pinyin-reading:<reading>` 选择读音，空读音恢复自动。
不支持此 UI 的平台继续忽略未知动作，不改变既有提交动作顺序。
自选组词学习同时保存带音节边界的读音索引；旧记录没有足够边界信息时不会覆盖明确的手动分词。
第三方模型与词库版权、许可证不变。
