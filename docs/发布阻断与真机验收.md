## 每个平台必须记录的证据

- 构建工具与 SDK 精确版本、提交 ID、产物 SHA-256 和签名身份。
- 冷启动与热路径 P50/P95/P99、峰值 RSS、24 小时稳定性、崩溃日志。
- 普通、密码、邮箱、URL、终端/代码文本框的输入与零学习/零网络断言。
- 中英切换、候选键/点击、组合光标、emoji/组合字符、焦点切换和应用崩溃恢复。
- 离线、弱网、磁盘满、词库损坏、模型缺失、权限拒绝和后台进程退出降级。
- 麦克风首次拒绝/允许/撤销、录音指示、取消清理和原始音频不落盘验证。
- 升级、降级拒绝、数据迁移、加密导出/恢复、设备撤销和彻底删除。
- 无障碍、横竖屏/缩放/高对比度、本地化及安装/卸载残留。

只有表中责任项都有真实报告，才能把对应平台从“源码/边界已实现”改为“发布完成”。
