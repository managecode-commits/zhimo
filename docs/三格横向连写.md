# 离线字形默认开启与三格横向连写

三格限制已被 [不限格连写与手动分字](不限格连写与手动分字.md) 替换，本文跨格拒绝及三格 APK 为历史版本；字形默认开启的设置策略继续保留。

日期：2026-09-13。本版替换此前停顿叠写，不再按停顿时长猜测字界。

## 使用

- 未设置过字形开关时，离线字形模型默认开启，手写默认显示“三格连写”。此前明确关闭过开关的用户保留关闭状态；可在设置中重新开启“实验性离线字形识别”，重新打开手写生效。
- 在画板从左到右每格写一个字，最多三个字。没有等待时长要求，也不需要按“下一字”；可以回到前一格补笔。空白格略过，不插入空白字符。
- 顶部候选显示整句，选择合适候选或点“整句上屏”。有笔迹时空格/回车也先确认首候选，不额外插入空格或发送。
- 写完三个字后先上屏，再继续写下一组。笔画不要跨格；跨格会显示错误并保留笔迹，可以撤笔重写。
- 可切换“单字”，复杂字可用完整画板。切换模式前必须上屏或清空当前笔迹。
- 撤笔只撤最后一笔，清空只清当前画板。没有笔迹时删除键才删除编辑器文字。提交失败不清空；切换输入框、关闭视图时取消未提交笔迹，不跨编辑器转移。

## 实现边界

这是三格空间分字的横向连写，不是任意位置、不分格、跨字一笔连接的自由连写。单字内部连笔仍由所选单字模型识别。本版不新增整行 OCR 模型，不声称实现任意连续笔迹的可靠自动分字。

每次识别保留完整画板快照，按横向格子分组，复用同一个离线 Provider 逐格识别，再按候选排名和组合最多 50 条整句候选；多字时最多取每字前 20 候选，只写一个字时保留最多 100 候选，不是语言模型语义纠错或校准概率。空白格不输出空格，字序由格子位置决定，不由笔顺或停顿决定。跨格笔画整次拒绝，不偷偷截断。轨迹仍有 64 笔/32768 点等输入上限。

原有停顿阈值、下一字暂存、32 字叠写草稿及其界面已移除；旧版安装包和历史说明保留。新模式没有旧草稿的逐字弹窗纠错，改为选择整句候选，或撤笔、补写、清空后重写。

字形模型仍是同一个内置模型，仍需独立准确率和真机性能验收；默认启用是用户要求的默认设置调整，不代表已通过正式模型质量门槛。关闭字形后默认回到原轨迹单字模式，也可手动切三格连写复用轨迹 Provider。所有轨迹仅在内存处理，不联网、不读取聊天文本、不保存笔迹。

共用候选/工具顶栏、拼音 9/26 键及数字符号输入保留。仅 Android 本次接入，其他平台不在本轮范围。


测试新增：默认开关/明确关闭、横向字序与笔顺独立、跨格拒绝、候选数量上限、补充平面汉字、真实离线两字识别，以及停顿后仍保留全部笔迹、撤笔和整句确认。旧叠写草稿测试随旧实现移除，不能继续计入新能力证据。
