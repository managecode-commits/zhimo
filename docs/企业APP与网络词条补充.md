# 企业、APP 与网络用语词库补充

评估日期：2026-09-24。

## 覆盖情况与本轮范围

原始词库已经包含腾讯、华为、网易、阿里巴巴等名称，但对微信、抖音、小红书等 APP 名和近年网络表达覆盖不足。
本轮在项目维护词库中补充 172 条：企业／品牌名 50 条、APP／服务名 60 条、网络表达 62 条。
这是常用场景的第一批整理，不是全国企业全集、APP 热度排名或完整流行语榜单。
已有基础词库中的名称作为权重覆盖维护，不声称 172 条都是整个词库中首次出现的新词。
同一名称既是企业又是服务时只维护一行；上轮舵机相关 36 条保留。

| 类别 | 代表词条 |
|---|---|
| 企业与品牌 | 字节跳动、宁德时代、大疆、比亚迪、米哈游、泡泡玛特、顺丰、招商银行 |
| APP 与服务 | 微信、企业微信、抖音、小红书、哔哩哔哩、剪映、高德地图、腾讯会议、豆包 |
| 网络表达 | 内卷、躺平、情绪价值、松弛感、表情包、直播带货、数字游民、具身智能 |

## 取词和拼音原则

- 收录常见中文短名与实际中文产品名，不拼凑企业法定全称，不把别名误当成法律实体名称。
- 多音字按词义标注，例如银行 `yin hang`、长安 `chang an`、弹幕 `dan mu`、音乐 `yin yue`、调制 `tiao zhi`。
- 使用汉字逐字对应的无声调音节；兼容全拼、分词符和九键检索。QQ、WPS、DeepSeek、12306 等英文／数字名称不强行汉字化；混合名称与字母别名应单独设计规则和测试。
- 基础名称、品牌和普通词可以同音；不删除普通词，不建立品牌强制置顶逻辑。
- 企业／APP 权重为 1000–2200，网络表达为 600–1500，均为人工编辑优先级，不是实测使用频率。核心合并重复项时保留较高权重，个人学习仍沿用原有机制。
- 不把短期热梗全部设为高频词；默认候选还受已有词频、匹配精度和个人学习影响，不保证所有新增词都是第一候选。

## 维护与验证

唯一维护源：`crates/ime-engine-pinyin/data/curated_phrase_lexicon.tsv`。
通过 `tools/sync-curated-lexicon.py` 生成 Android Rime 字典，避免维护两份词条。
Android Rime 资源版本由 11 升至 12，使后续安装更新能刷新共享资源；不更改用户词库目录。

```sh
python3 tools/sync-curated-lexicon.py
python3 tools/sync-curated-lexicon.py --check
cargo test -p ime-engine-pinyin --locked
```

现有逐条回归检查重复项、音节／汉字数、正权重，以及全拼、显式分词和九键是否能找到每个维护词条；同时检查生成的 Rime 内容与维护源一致。
这不等于所有新增词的简拼首屏排名或真实手机 Rime 运行均已验收。
词库整理阶段仅更新源码；随后纳入 `v0.1.1-preview.20260924.1` Android 发布，已安装版本需升级该 APK 才能获得词条。桌面端需后续重新编译。
