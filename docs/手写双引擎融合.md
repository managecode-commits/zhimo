# 手写双引擎融合

用户确认“比、观、动、从、响”在 `zhimo-handwriting-bilateral-20260914-debug.apk`
中仍有误识别。上一轮几何保护不覆盖所有连笔、大小偏旁，不能视为准确率问题已解决。

## 本轮实现

- 中文和混合模式把内置图像、轨迹模型的汉字候选按 reciprocal rank 合并：每个引擎贡献 `1/(8+名次)`，名次从零开始。两者都支持的候选可获得更高排序。
- 混合模式继续按三个汉字、一个数字/字母安排候选；专用数字、字母模式只加载图像模型，避免额外开销。
- 保留明确关闭图像模型后的轨迹单引擎设置。某一引擎不可用或识别报错时，使用另一引擎的结果；两者失败则报告失败。
- 关闭面板后丢弃回调，关闭两个模型；不新增联网、下载、上传、权限或笔迹持久化。
- 自动分字、手动分字以及逐字纠正仍使用已有方案。没有按“又见→观”等字对硬编码，也没有为了单字强制合并真正的多字连写。

## 验证与限制

截图不包含原始抬笔与时间信息。测试中的“比、观、动、从、响、北、物”和连笔变体均为人工重建，
不是用户实际触控记录，不能据此计算真实用户准确率。融合仍是候选名次启发式，未校准置信度，未训练新模型。
整字进入候选不等于首选正确，分字结果仍可能排第一。新链路增加了汉字推理工作量，需要手机实测延迟和内存。

验收包括两引擎候选合并、失败降级、专用模式、生命周期、真实模型重建样例、连写“从左”、面板及实际键盘流程。
最终结果见下方记录；不能将单纯编译通过当作识别准确率通过。
