## 当前环境约束

- 本机可验证 Rust、C ABI、Python GI 与 IBus 会话；Shurufa 已通过用户级安装被 IBus 发现并激活为全局引擎。
- 本机已从源码验证 librime 与 whisper.cpp；构建产物/模型在临时目录，不纳入仓库。
- Fcitx 5 开发包和 cmake 未安装到系统；已使用隔离的 Fcitx 5.1.19 SDK 与 CMake 完成原生插件编译链接，桌面运行时加载仍需目标环境。IBus Python/GI 可运行。
- Windows TSF 的 C++ 源码已用 MinGW Windows 头文件严格编译，并与 `x86_64-pc-windows-gnu` Rust DLL 链接成 PE32+ DLL；实际 TSF 注册、签名和应用兼容仍需要 Windows SDK 与 Windows 测试机。
- macOS/iOS 需要 Xcode、Apple 签名账号和 Apple 设备。
- Android SDK/NDK 许可证已由项目责任人接受；Debug APK、AndroidTest APK 和无签名 Release 变体已构建，Lint、静态产物及 API 35 x86_64 模拟器验收通过。剩余 Android 外部条件是授权真机兼容矩阵、生产 Android librime 三 ABI 前缀和发布签名。
- 真实语音质量验收需要合法授权语料和多档真实设备。
