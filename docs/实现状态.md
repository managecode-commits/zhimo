## 尚未达到产品完成的项目

- 生产发行所需的完整 Rime 数据包、简繁/双拼/模糊音默认配置和词库许可证清单。
- 更完整的中英文自动混输、整句语言模型、简繁/双拼/模糊音与生产排序模型。
- sherpa-onnx 真流式 Provider、完整中英 ITN、说话人分离；桌面平台麦克风后台服务尚未落地。
- 操作系统 Keychain/Keystore/DPAPI/Secret Service 密钥接入及恢复密钥 UX。
- 正式多租户账户、令牌签发、限流、审计、TLS 部署和灾备；当前服务是单账户闭环。
- Windows TSF COM 产品壳；Fcitx 5 和 Apple 源码仍需各自目标工具链编译与真机调试；Android 已完成目标工具链编译和模拟器验收，尚需真机兼容矩阵。
- 配套设置 App、模型/词库下载、长音频转录 UI。
- 安装签名、应用商店发布、真机兼容矩阵、无障碍和本地化。
- 公开 SDK 稳定性承诺和可视化 Studio（第二语种参考引擎已完成）。

## 当前环境约束

- 本机可验证 Rust、C ABI、Python GI 与 IBus 会话。
- 本机已从源码验证 librime 与 whisper.cpp；构建产物/模型在临时目录，不纳入仓库。
- Fcitx 5 开发包和 cmake 未安装到系统；已用官方二进制包解包头文件完成编译探针，桌面运行时加载仍需目标环境。IBus Python/GI 可运行。
- Windows TSF 需要 Windows SDK 与 Windows 测试机。
- macOS/iOS 需要 Xcode、Apple 签名账号和 Apple 设备。
- Android SDK/NDK 许可证已由项目责任人接受；Debug APK、AndroidTest APK 和无签名 Release 变体已构建，Lint、静态产物及 API 35 x86_64 模拟器验收通过。剩余 Android 外部条件是授权真机兼容矩阵、生产 Android librime 三 ABI 前缀和发布签名。
- 真实语音质量验收需要合法授权语料和多档真实设备。
