# Android 拼音预编辑与上屏

针对 2026-09-14 的 9 键、26 键截图：应用输入框中的下划线字母或数字来自
`setComposingText`，不是用户主动选择的文字。26 键候选没有注音时，键盘也没有独立的拼音显示。

## 本轮调整

- 中文拼音的 `UpdateComposition` 只保存在输入法内，不调用编辑器的 `setComposingText`。
- 有待选拼音时在候选区上方显示预编辑；清空、上屏、结束输入后隐藏，不留空白行。
- 26 键显示引擎提供的预编辑拼音；9 键优先显示首候选的拼音注释，没有注释时仅在键盘内显示编码。
- 只有引擎提交动作才向应用写入文字。保留选词、空格确认、回车确认以及原有标点/模式切换确认行为。
- 英文模式以及主动点击数字、符号的直接输入不受影响。

这次采用键盘内部的动态预编辑行，不申请悬浮窗权限；没有逐词推测缺失的读音，也没有实现参考图中的 9 键音节筛选侧栏。

## 回归要求

真实编辑器流程增加断言：26 键输入 `nihao` 后编辑框保持空白，并显示拼音；
9 键输入 `64426` 后编辑框保持原文，并显示 `ni hao`；确认后才出现“你好”。
同时保留标点、数字、清空和模式切换的既有测试。

## 连拼缺词补充

用户补充“履带（lvdai）”“物联网（wulianwang）”无法连拼。检查固定版本的上游词库，
它包含“履（lv）”“物（wu）”“联网（lian wang）”，但没有这两个完整词条。
`v` 本身不是这两个样例的根因；9 键/回退引擎按词条前缀检索，不具备任意未知词自动组句能力。

- 新增自有 `zhimo_pinyin.dict.yaml`，导入未改动的上游 `pinyin_simp`，补充这两个词。
- 共享回退/9 键词库同步加入词条，覆盖 `58324` 和 `9854269264`。
- Android Rime 资源版本从 3 升至 4，覆盖安装会更新共享词库，保留 user 目录。
- Rust 回归覆盖全拼、分隔符和九键编码；Android 回归要求原生 Rime 和回退引擎均召回目标词。

## 常用词补充与逐字选择（后续追加）

用户进一步要求扩充词条，并在没有整词时逐字选择。本轮追加：

- 从 [phrase-pinyin-data](https://github.com/mozillazg/phrase-pinyin-data) 固定提交
  `cee0ed6e6e4898580cafd2bd5e3723e20b214aa0` 的 `pinyin.txt` 补充 36,915 组词语读音，
  与原有数据合计 102,048 组；不是 102,048 个不同汉字，也不是“所有常用词”的覆盖率声明。
- 保留 MIT 许可证；没有导入 `large_pinyin.txt` 或其额外混合来源数据。
  `tools/update-common-pinyin.py` 固定源文件和许可证 SHA-256，并同时生成 Android Rime 与共享引擎词库。
- 过滤为 2–8 个汉字、每字一个合法拼音的条目，去声调并把 ü 转为 v；
  没有可靠词频的补充条目权重设为 1，不将低频/古语词当成高频词。
- 共享引擎新增开头音节单字候选；候选 ID 携带消耗的原始输入长度。
  选择一个字只提交已选文字，余下拼音继续组成候选，分隔符和九键编码同样保留。
- 26 键原生 Rime 使用其现有部分选词机制；已选择但尚未整句提交的内容继续在键盘内预编辑。
- 未选完时切换模式不会丢弃剩余输入；会提示继续选字或清空。部分选字后的退格编辑剩余拼音。

Rust 回归覆盖 `maolvbei`、`mao'lv'bei`、`62658234` 依次选择“猫、驴、杯”，
以及 `nihaox` 选择“你”后保留 `haox`，防止错误吞掉后缀。

## 用户组词与频率学习（追加）

- 共享引擎记录每次已确认的单字/词。完成多次选择后，再保存完整的拼音与最终组词；
  清空、关闭会话、未完成输入不会保存为完整新词。已选单字仍可计入自己的频率。
- 学到的新词参与检索，而不只是给系统词库里已有的词加分。
- 相同输入的候选优先比较用户有效选择次数，再比较静态词频；删除/负反馈记录仍被尊重。
- 新记录同时保存全拼和九键映射，共享引擎两种布局互通；拼音分隔符不会把频率分成不同记录。
- 通过已有 SQLite 用户词库持久化，不联网、不上传输入。密码框或禁用学习时不新增记录。
- 原生 26 键 Rime 仍使用其自身的本地用户词典及排序机制；它与共享引擎 SQLite 是两套存储，
  本轮不宣称原生 Rime 与九键之间已完成用户词库双向同步。

共享引擎当前 16 项测试通过，包含完整组词重载、频率排序、取消未完成词和密码范围不学习。
Android 另增加真实 SQLite 保存后销毁/重建运行时的测试，验证整词与单字排序是否保留。

限制：这不是任意长句的语言模型自动组句，也没有新增九键音节筛选侧栏。
逐字选择覆盖已有单字词库，不能识别词库中不存在的字或修复所有错误拼音。
