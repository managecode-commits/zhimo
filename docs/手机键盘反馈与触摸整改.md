## 兼容修订：音色不自然、滑条无变化、系统音无声

以下为当前修订；下文的 30ms 正弦音、仅 CLICK primitive 调强度及旧 APK 哈希是上一轮交付记录。

代码核查发现：旧音效带固定音高；振动能力判定遗漏了支持振幅但不支持 CLICK primitive 的设备；系统触摸音关闭时会静默抑制播放，设置页没有解释或试听。

- 内置音改为 12ms、无固定音高的带限噪声瞬态，仍是原创合成音，不能声称已在所有手机上试听自然。
- 振动优先使用 `hasAmplitudeControl` 和固定 9ms 包络调振幅，再兼容 CLICK primitive；两者都不支持时仅显示开关，不显示无效的百分比滑条。0 为不振动，100 为当前路径上限；不靠延长震动时间伪装调强弱。
- 系统触觉设置没有此字段时不再错误地等同于明确关闭；有明确关闭值时仍遵守关闭。平台自身仍可限制触觉，不使用忽略系统策略的标志。
- 系统音预加载，改用通用点击音效。切换音色后试听，并显示触摸音关闭、静音、勿扰、系统音量为零、通话和资源加载等状态。系统音依赖厂商资源且播放 API 没有可听成功回执，无法保证每台手机有此声音，也不擅自打开系统触摸音开关。
- 新增系统声音设置入口；返回应用自动刷新状态。默认音效仍开启，内置模式沿用已有 `soft` 偏好值，无需清除设置或个人词库。
- 新增振动后端选择/振幅递增测试，以及 WAV 长度、削波、端点、单频占比检查。信号检查不等于音色盲测。

尚待用户手机验证实际振幅差异、预览与输入的一致性，以及系统音资源是否可用。请反馈机型、Android 版本及设置页显示的原因；不能把本机编译或能力 API 返回值当作用户硬件的实测结果。

## 默认行为

- 按用户要求，按键音默认开启，默认柔和音色；设置中可关闭或切换系统音色。
- 触觉反馈使用 0–100 滑条，0 为无，分为弱、中、强、最强；初始值 35，迁移时尊重原有关闭设置。拖动时最多每 80ms 预览一次，预览不播放声音。
- 支持 Android CLICK primitive 的设备采用短触觉效果并缩放强度，0 完全不调用效果（primitive 的零 scale 本身不代表关闭）。不支持时明确提示仅支持系统强度；不用拉长振动时间伪装强度。
- 为可调效果新增普通 `VIBRATE` 权限，无运行时授权弹窗；遵守系统触觉关闭及勿扰策略。不改变系统设置或突破硬件上限，100% 不是跨设备相同物理强度。
- 设置页提供试用按钮：轻点普通反馈，长按体验长按反馈。音效尚未加载时不阻塞、不补播。
- 静音、振动模式、勿扰、通话模式或系统音量为零时抑制音效；无法确认系统策略时不播放。系统音色还遵守系统触摸音开关。
- 本输入法录音或转录时抑制声音与振动，暂停已播放的自定义声音；不更改系统音量，不抢音频焦点。

## 实现

`KeyboardFeedbackController` 统一管理系统触觉、音效池、设置及限频；由输入法和设置页分别拥有并在销毁时释放。`KeyboardFeedbackPolicy` 为可单独测试的策略。

普通键在按下时反馈；触摸点击松手不重复反馈，无障碍激活仍可反馈。长按功能显式反馈一次，禁用按钮自带的长按振动与点击声音，避免叠加。候选文字按钮在点击时反馈。手写功能与候选按钮接入统一控制，不对书写笔画播放音效。

柔和音为项目原创合成 30ms 单声道 WAV，生成器 `tools/generate-key-sound.py`，无第三方采样。SoundPool 异步预载，最多两个声音并发，35ms 音效限频。连续删除反馈最多每 130ms 一次，而删除逻辑仍每 65ms 执行。

按键圆角保留，背景内缩模拟水平 4dp、垂直 6dp 间隙；按键外边距改为零，使内部触摸区域连续且不重叠。不会将键盘外围空白吸附成字符。

按键滑出边界后发送取消事件，滑回也不恢复本次点击。连续删除移出、取消、切换布局或离开输入视图时停止；回调在布局更新后不重新挂起旧的循环。此处采用确定性取消，不实现滑行输入或自动改选邻键。
