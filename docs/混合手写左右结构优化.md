# 混合手写与左右结构单字

用户确认 2026-09-14 的截图目标字为“比”，前排却显示 `t`、“七七”。
这是混合字符竞争与左右结构分字解释共同作用的表现，不能仅凭截图推断完整候选中一定没有“比”。

## 调整

图像识别解码时，汉字和数字/字母使用独立的前 100 候选池，避免在混合截断阶段互相挤掉。
混合模式每轮最多取 3 个汉字和 1 个数字/字母，再截断到总共 100 项。
这是中文优先的候选配额，不是模型置信度校准，也没有修改模型或写入目标字特例。

中文、数字、字母专用模式保持原有排序。纯数字/字母候选池仍能完整返回，
混合输入英文时可能需要选择后面的候选，明确输入英文/数字可使用对应专用模式。

现有完整字形与空间分字方案继续共同参与候选，不强制合并或拆分笔画。
对自动分字中较紧凑的笔迹（宽高比不超过 1.6），若左右两部分各至少两笔，且高度均达到整体的 55%，
则优先展示整字解释。整字候选若与任一侧的前两个汉字候选相同，会让位给最多三个非部件候选；
所有原候选及数字/字母所在位置仍保留。这是有限的几何与部件假设，手动分字和专用数字/字母模式不使用它。
它适用于汉字与 `t`、`b` 等相似字形竞争的同类情况，但并不保证所有左右结构字首选正确。
