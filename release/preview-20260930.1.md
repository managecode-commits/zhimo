# Zhimo 知墨 Android 连拼学习与个人词库

版本：`v0.1.1-preview.20260930.1`，Android versionCode 7。本版改进连拼缺词时的逐字组词学习，并增加个人词库管理入口。

## 本版变化

- 默认开启统一拼音学习，九键和 26 键共用自研拼音引擎与本地个人词库。
- 连拼没有合适整词时可逐字选择；完成同一次组合后记录新词，首次学到的新组合会提示“已记住新词”。已学词可参与较长输入的词典组句。
- 工具菜单增加“个人词库”，分页查看文字、拼音和学习分；长按候选可降低学习优先级或删除学习记录。
- 增加“撤销上次学习”，只撤销当前会话最近一次学习事务，不修改应用输入框文字。
- 关闭个性化学习、密码框及要求不学习的输入环境，禁止查看或修改个人词库。
- 保留按键反馈默认关闭，以及按住空格录音、松开结束、语音最终结果直接上屏。

## 升级与限制

旧 Rime 学习文件保留，但不自动转换或合并。设置中关闭“统一拼音学习”并重新打开键盘，可让 26 键恢复旧 Rime 兼容模式；兼容模式与统一模式的数据不自动互通。

删除学习记录不等于删除系统词条或永久屏蔽候选。自动组句仍是有限宽度的词典搜索，不是上下文语言模型；长句和歧义读音仍可能需要手动分词、逐字选择。详见[连拼学习与个人词库说明](https://github.com/managecode-commits/zhimo/blob/v0.1.1-preview.20260930.1/docs/连拼学习与个人词库.md)。

APK 支持 Android 8.0+，包含 arm64-v8a、armeabi-v7a、x86_64，内置 Rime、手写与流式语音模型，约 329 MiB。使用调试签名，与上一预览证书相同；若提示签名不匹配，先保留个人数据，不要贸然卸载。校验和与构建记录见附件 `SHA256SUMS`、`BUILDINFO.txt`，校验和不等同于发布者身份认证。

本轮只更新 Android 安装包及共享核心源码，未新增桌面个人词库管理界面。桌面安装包继续使用 [20260921.1 预览版](https://github.com/managecode-commits/zhimo/releases/tag/v0.1.1-preview.20260921.1)。

## 验证情况

- Rust 拼音 33 项、FFI 13 项测试通过；手动性能测试与需专门配置的桌面 Whisper 测试各忽略 1 项。
- Android 单元测试 28 项、构建、Lint、APK 签名与原生库及模型完整性检查通过。
- API 35 x86_64 模拟器在 720×1280、280 DPI 下通过 13 项运行时及键盘交互测试，覆盖个人词库管理、持久化、隐私和旧 Rime 兼容链路。

真实手机准确率、长期词库增长后的性能、语音延迟与发热，以及极小逻辑屏幕布局仍需验收。
