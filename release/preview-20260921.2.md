# Zhimo 知墨 · Android 流式语音预览

版本：`v0.1.1-preview.20260921.2`，Android versionCode 5。

## 本版变化

- Android 移除 Whisper 和独立 Silero VAD，只内置离线流式语音模型，无需下载模型或调用云端识别。
- 长按空格开始录音，松开结束，最终识别文字直接上屏，无需确认；临时结果仅显示在键盘内。
- 手指滑出按键取消；短按保留空格／选词功能，松手不会多输入空格。准备期间松手会取消，不会稍后自动开启麦克风。
- 移除旧语音开关和不再生效的配置；仅清理应用私有目录内两个已知旧模型文件，不清除个人词库。

## 下载与安装

下载附件 `zhimo-v0.1.1-preview.20260921.2-android-debug.apk`。
Android 8.0+；包含 arm64-v8a、armeabi-v7a 和 x86_64；调试签名，与上一预览 APK 使用相同证书。
安装后按引导启用知墨并授予录音权限。若提示签名不匹配，先备份个人数据，不要贸然卸载。

大小：339,142,698 字节，约 323 MiB。流式模型体积较大，本包大于上一版仅含 Whisper 的约 180 MiB APK；并非同时携带两套语音模型。

SHA-256：`76eaad273660dbc953da6937185aaf940c2736152105af2c4c7fda3bdcdbeeeb`。
校验和只用于检查完整性，不代表正式发布者签名。

## 验证与限制

- Gradle 构建、Lint、27 项 JVM 测试通过。
- 最终 APK 在 API 35 x86_64 模拟器上通过 2 项流式模型测试和 1 项按键 UI 集成测试，包含公开语音样例与实际 DOWN/UP 按住录音操作。
- APK 的三 ABI、JNI、模型与许可哈希检查通过，确认没有 Android Whisper 库及旧模型资产。
- 首次模型准备需要时间，请等录音就绪后说话；松手后仍可能需要等待最终解码。单次录音最长 60 秒。
- 真实手机的中文口语准确率、低端 ARM 设备速度、发热和权限变化仍需验收，不承诺零延迟。

这是 Android 专项预览，本轮没有重新编译桌面安装包。Windows、Ubuntu、Debian、macOS 请使用[上一版发布页](https://github.com/managecode-commits/zhimo/releases/tag/v0.1.1-preview.20260921.1)，桌面 Whisper 链路未变。
