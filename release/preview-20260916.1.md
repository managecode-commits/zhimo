## 安装与限制

- Android 为 debug 签名预览 APK，不是正式商店版本。升级前备份个人学习数据；签名不同不能直接覆盖安装。
- Windows 为包含 x64 和 x86 输入法的未签名测试包；系统可能提示安全警告。不绕过组织安全策略。
- Ubuntu 24.04、Debian 12 为 amd64 包：安装 zhimo-core，再按正在使用的输入法框架选择 zhimo-ibus 或 fcitx5-zhimo，不需要同时启用两套框架。
- 不包含新编译的 macOS/iOS/HarmonyOS 安装包。
- Linux 新离线字形融合实验尚未接入，本版本仍使用现有桌面手写链路。
- 构建检查不等于 Windows/手机实机体验验收；手写准确率和不同设备音色、振动效果仍需实测。

请在本页附件下载对应平台安装包，并使用 SHA256SUMS 校验文件完整性。校验和不代表发布者数字签名。
