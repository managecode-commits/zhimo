## 更新

- Android 快速输入：串行后台查询、候选控件复用、按键气泡复用及反馈线程优化，减少主线程开销；不丢弃输入事件。
- 虚拟键盘圆角由 9dp 缩小至 5dp，缩小视觉键间距，保留原触摸范围。
- 9 键新增有界词典组句和后续候选翻页；回车/完成键选汉字，不提交内部数字编码；读音提示不再跟随首候选排名猜测。
- 桌面 Caps Lock 临时英文直输，关闭后恢复基础语言模式；Shift＋字母交回系统处理。已有拼音按原文提交，不误选汉字。IBus 同时修复结束组合消息未收起旧拼音的问题。
- 提交离线流式语音实验代码、测试和准备工具；**此次公开 APK 不启用实验流式模型**。用户已反馈部分手机无法使用，故保留默认 Whisper 离线语音，不以扩大安装包替代实机验收。

## 下载与安装

- Android：三 ABI、debug 签名预览 APK，内置 Rime、手写和 Whisper 离线语音。不是商店正式版本；签名不同不能覆盖安装，升级前备份个人学习数据。
- Windows：x64 Windows 使用的 x64/x86 TSF 双架构测试包，覆盖 32 位应用。未进行发布者数字签名，升级后注销登录，避免继续加载旧 DLL。
- Ubuntu 24.04 / Debian 12：分别提供 amd64 的 core、IBus、Fcitx5 deb。选择本机发行版，安装 core 与正在使用的一个输入法框架插件；不要混装不同发行版包。
- macOS：若附件提供，则为 GitHub macOS 构建产物，需以对应构建记录为准；未公证的测试包不代表正式发行，不建议绕过组织安全策略。
- iOS、HarmonyOS、其他 Linux 发行版本次不提供新安装包。

## 验证与限制

- 核心、按键路由、构建与安装包完整性分别校验；具体日志/构建状态见随包 BUILD-INFO 和 GitHub Actions。
- 9 键组句仍为词典驱动，不是上下文语言模型；任意音节编辑、语义排序及误选撤销仍未完成。
- 26 键 Rime 的履带、物联网、你好中国、简拼及分词已有模拟器验证；不能据此声称所有手机都通过。
- Windows/EmEditor、macOS IMK、Linux X11/Wayland 的实际宿主兼容性，以及手机准确率和 P95/P99 延迟，仍需实机验收。
- 新增 Linux 字形融合源码和准备脚本仍未接入桌面默认手写链路，不宣称本次已启用该能力。

使用附件中的 SHA256SUMS 校验文件完整性；校验和不是发布者数字签名。
